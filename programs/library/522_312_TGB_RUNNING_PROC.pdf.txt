                Procedure for running Temporary Guide Base
                                 (TGB)

1)  Fill bays in TGB with 80-100 bags of barite spreading the load evenly amongst
   the bays
2)  Lift TGB to Christmas tree skid and set on and move under rotary
3) Connect all 4 G/line tensioners to the TGB
4) The TGB Running tool body is already installed in the base
5) Pick up TGB Running tool stem and make up to running string
6) Make up tool stem to drillpipe then run stem through rotary and bolt to body of
    tool
7) Pick up test
8) Pick up and skid Christmas tree trolley away
9) Run TGB through splash zone
10) Run TGB paying out tensioner wires as required ensuring tension in wires is
   balanced
11) Jump ROV
12) Land gently on seabed and tension up g/lines to support weight of TGB
13) Set down 5000lbs on tool and disconnect tool from TGB by rotating drill string to
   the right and watching for paint lines to line up
14) Recover tool to surface and disconnect stem from body and lay down
