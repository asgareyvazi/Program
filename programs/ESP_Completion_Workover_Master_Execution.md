## 1. SCOPE AND OBJECTIVE

### 1.1 Scope

This document covers the complete workover operation to:

1. Kill the existing well using emulsion fluid (DME-based low-density fluid).
2. Retrieve the existing completion string.
3. Perform corrosion logging on casing strings.
4. Inspect, redress, and re-certify all retrieved completion tools.
5. Replace / modify the Tubing Head Spool (THS) for ESP configuration, including cement and RTTS operations.
6. Perform hole cleaning, scraping, and drift verification.
7. Run new ESP completion string including all downhole and surface equipment.
8. Perform ESP cable splice to tubing hanger penetrator.
9. Land tubing hanger in THS.
10. Install tubing head adapter (with penetrator rod and exit blocks for TRSV CL and AGV CL) and X-mas tree.
11. Conduct ESP pilot test and well performance test.
12. Secure the well and release the rig.

### 1.2 Objective

- Successfully install and commission ESP completion.
- Zero HSE incidents.
- Minimize NPT through thorough pre-job planning and readiness.
- Document all test results, hold points, and handover data.
- Ensure all retrieved tools are inspected and either redressed or replaced for future use.

### 1.3 Key Notes

- No landing nipple is required in the ESP completion design.
- The tubing head adapter must have **two exit blocks**: one for TRSV control line, one for AGV control line.
- The penetrator rod on the tubing head adapter must be checked and verified before mobilization. If modification or machining is needed, coordinate with wellhead manufacturer in advance.
- A complete set of ESP-type THS/THA/XMT should be available as ready-to-install inventory, or pre-ordered and modified by the wellhead manufacturer.
- All completion tools (SSD, TRSV, XOs, pup joints) are to be provided by the contractor, not the ESP pump supplier. The pump supplier provides only: ESP pump, motor, protector, intake, gas separator, sensor, shrouds, centralizer, cable, MLE, BOD, sub pressure, and packer with accessories.
- Before running, tubing head adapter penetrator rod must be physically checked through the adapter. If machining or re-threading is required, coordinate with the wellhead manufacturer **before mobilization**.

## 8. DETAILED EXECUTION PROCEDURE – PHASE BY PHASE

### Phase 1: Rig-Up and Preparation

**Estimated Duration: 48 hours (2 days)**

#### 1.1 Rig Move and Rig-Up
1. Move rig to well location.
2. Level rig. Confirm level before any operation.
3. Rig-up all systems.

#### 1.2 Measurements and Reference Points
1. Measure and record:
   - RT elevation from ground level.
   - THS elevation from ground level.
   - RT to THS Tie-down Screw distance (landing reference).
   - Wellhead orientation / north reference.
2. Confirm these match program depths. Calculate and document any RTE correction.

#### 1.3 Stand Back Equipment
1. Stand back 5" DP, 3-1/2" DP, 2-7/8" DP (HT PAC).
2. Rack 4-3/4" DC, 3-1/8" DC, 3-1/2" HWDP.
3. All tubulars to be washed, drifted, and measured before use.

#### 1.4 Line-Up
1. Line up mud pump / pump truck to kill valve.
2. Line up flow line to choke manifold.
3. Line up THS side outlet to choke manifold if applicable.
4. Pressure test all surface lines.

#### 1.5 Wellhead Survey
1. Record all wellhead pressures (tubing, all annuli).
2. Bleed each section carefully.
3. Record pressure vs time, fluid type, volume, gas/H2S.
4. Fill annulus if empty.

#### 1.6 Pre-Job Safety Meeting
1. Conduct rig-level safety meeting covering scope, H2S hazards, emergency procedures, roles, BOP drill, communication.

---

### Phase 2: Kill the Well

**Estimated Duration: 12–28 hours**

#### 2.1 Kill Method Priority
1. **Primary:** Reverse circulation through SSD using DME emulsion fluid.
2. **Secondary:** Coil Tubing kill (if provided by Client as extra work).
3. **Tertiary:** Bullhead kill.

> **Note:** DME emulsion fluid is used to reduce hydrostatic weight and avoid losses during kill operation. The emulsion is mixed by adding DME additive to water and diesel.

#### 2.2 Slickline Operations for Kill Preparation
1. Rig up slickline equipment and BOP.
2. Pressure test SL BOP: 2500 psi.
3. Install TRSV protection sleeve if applicable.
4. Run gauge ring to 2m above guide shoe. POOH.
5. Set 2.562" RPT plug in No-Go landing nipple. POOH.
6. Set prong inside plug. POOH.
7. Shift SSD open using 2.750" shifting tool. POOH.
8. If SSD opens successfully, rig down slickline.

#### 2.3 SSD Shifting Contingency
If SSD does not shift:

- Redress shifting tool and re-attempt.
- Equalize pressure across SSD.
- If all attempts fail:
  - **Option A:** Proceed to Coil Tubing kill (CT RIH to guide shoe, displace with DME emulsion fluid, break circulation every 400m).
  - **Option B:** Proceed to bullhead kill with Client approval.

#### 2.4 Reverse Circulation Kill
1. Line up from annulus to choke manifold.
2. Pump DME emulsion kill fluid down annulus through SSD.
3. Monitor all pressures continuously.
4. Confirm well dead: shut in and monitor 30 minutes.
5. Close TRSV via control line if applicable.

#### 2.5 Bullhead Kill (Alternate)
1. Bullhead ±125 bbl DME emulsion fluid into tubing.
2. Monitor tubing and annulus pressure.
3. Confirm well dead.

### Phase 3: Decompletion

**Estimated Duration: 60 hours (2.5 days)**

#### 3.1 Prepare for Pulling
1. Install 4" TWCV in tubing hanger.
2. Pressure test TWCV: 4500 psi, 15 min.
3. N/D X-mas tree.
4. Check tubing hanger neck threads for damage.
5. Check all tie-down screws operate properly.

#### 3.2 Nipple Up BOP and Test
1. N/U BOP stack (DSA + Riser + Fix Rams + Double Rams + Annular).
2. Pressure test all BOP components per test matrix.

#### 3.3 Retrieve TWCV and Connect Landing Joint
1. Retrieve 4" TWCV.
2. Make up landing joint / XO to tubing hanger.
3. Connect pump truck and verify well not flowing.

#### 3.4 Unset Packer and Pull Completion
1. Open tie-down screws.
2. Pull up to unset packer per OEM procedure.
3. POOH completion string while:
   - laying down each component,
   - monitoring fluid levels,
   - retrieving control line and gauge cable on empty reels,
   - inspecting pulled components.

> **CRITICAL: All retrieved tools must be sent for inspection as soon as possible (see Section 11).**

#### 3.5 Decompletion Contingency
If packer does not unset:

1. Run electrical back-off tool.
2. Back off above packer.
3. Pull free tubing.
4. Mill out packer.

> **If packer is permanent type:**
> Before milling, set a cement plug below packer depth to prevent debris from falling into the well and damaging the ESP pump later. The well must be clean before running ESP.

### Phase 4: Corrosion Logging

**Estimated Duration: 24 hours (1 day)**

#### 4.1 Corrosion Log Run
1. After completion string is fully retrieved and hole is open:
2. Rig up corrosion logging equipment.
3. Run corrosion log inside 9-5/8" casing and 7" liner as required.
4. Record casing wall thickness, pitting, corrosion anomalies.
5. POOH and rig down logging equipment.
6. Submit log results for interpretation.

> **Decision Point:** Based on corrosion log results, Client and Contractor will decide:
> - Whether casing integrity is acceptable for ESP completion.
> - Whether remedial cementing or casing repair is needed.

### Phase 5: Tubing Head Spool Change

**Estimated Duration: 48 hours (2 days)**

#### 5.1 Scrape for RTTS and Packer Area
1. Run 9-5/8" scraper to ±150m (RTTS + new packer depth area, approximately 100-150m below RT).
2. Scrape by reciprocating.
3. POOH.

> This scraper run must be done before running ESP to ensure clean casing for packer setting.

#### 5.2 Set Cement Inside 7" Liner (For RTTS Integrity / Contingency Dry Test)
**This step is required if:**
- A dry test of the 7" liner lap is required as contingency, OR
- RTTS integrity requires cement support.

1. RIH cementing string.
2. Set cement plug inside 7" liner at required depth.
3. POOH cementing string.
4. WOC (Wait on Cement).
5. Pressure test cement plug (dry test).
6. If dry test from 7" liner lap is required:
   - Set RTTS above 7" liner lap.
   - Pressure test from above RTTS against cement inside liner.
   - This confirms 7" liner lap integrity.

#### 5.3 Set RTTS
1. RIH RTTS packer assembly.
2. Set RTTS at ±30-40m.
3. Back off string. POOH.
4. Perform RTTS integrity test: 800-1000 psi, 10 min.

#### 5.4 N/D BOP
1. N/D BOP stack completely.

#### 5.5 N/D Old THS
1. De-energize P-seals.
2. Open THS studs.
3. Lift and lay down old THS.

#### 5.6 Prepare Casing Neck
1. Inspect 9-5/8" casing neck (inner/outer seal surfaces, length, profile).
2. If required: cut, bevel, dress casing neck.
3. Requires permit, cutting tools, welding support, Client approval.

#### 5.7 Install New ESP THS
1. Install new ESP-compatible THS.
2. Use new ring gasket.
3. Tighten studs.
4. Inject P-seal packing compound.
5. Pressure test all P-seal zones: 4000 psi, 15 min.
6. Pressure test body and gate valves: 4500 psi, 15 min.

#### 5.8 Reinstall BOP and Test
1. N/U BOP and test per test matrix.

#### 5.9 Retrieve RTTS
1. RIH and screw into RTTS assembly.
2. Unset RTTS.
3. POOH.

### Phase 6: Hole Cleaning, Scraping, Drift Verification

**Estimated Duration: 124 hours (5.2 days)**

#### 6.1 TD Check Run
1. P/U cleanout BHA:
   - 3-1/4" flat bottom junk mill + 3-1/8" bit sub (with float valve) + 3-1/8" DC (4 jts) + 2-7/8" DP (HT PAC, jt by jt).

7. Break circulation every 100-200m.
8. POOH. Inspect all scrapers and mills.

## 10. CORROSION LOGGING

### 10.1 Scope
After removing the completion string and before THS change, run a corrosion log inside the 9-5/8" casing and 7" liner.

### 10.2 Purpose
- Evaluate casing wall integrity.
- Identify corrosion pitting, wall thinning.
- Confirm suitability for new ESP completion.
- Provide baseline data for future comparison.

### 10.3 Procedure
1. Rig up logging equipment.
2. Calibrate tool.
3. RIH to target depth.
4. Log while POOH at controlled speed.
5. Rig down.
6. Deliver raw and interpreted data.

### 10.4 Decision Point
Based on results:

- If casing integrity acceptable → proceed to THS change.
- If remedial action needed → discuss with Client (cement squeeze, casing patch, etc.).

## 11. INSPECTION AND REDRESSING PROGRAM

### 11.1 Scope
All retrieved completion tools and tubing must be inspected as soon as possible after POOH. The goal is to determine:

- Which items can be redressed, tested, and reused.
- Which items need cut & re-thread.
- Which items need to be replaced with new.

> **New items always have higher reliability. For first-time ESP execution, purchasing new SSD, TRSV, and XOs is recommended to increase confidence.**

### 11.2 Inspection Sequence

| # | Item | Inspection Scope | Action if Pass | Action if Fail |
|---|---|---|---|---|
| 1 | Tubing 3-1/2" and 4-1/2" | Visual, drift, thread inspection, wall thickness | Clean, re-dope, return to stock | Cut & re-thread if body OK; scrap if body damaged |
| 2 | SSD | Visual, profile check, function test, pressure test | Redress, replace seals, fabricate pup joint, test | Replace with new |
| 3 | TRSV | Visual, profile check, function test (open/close), pressure test | Redress, replace seals, fabricate pup joint, test | Replace with new |
| 4 | XOs | Thread inspection, drift | Re-dope, return to stock | Cut & re-thread or replace |
| 5 | Pup Joints | Thread inspection, drift | Re-dope, return to stock | Cut & re-thread or fabricate new |
| 6 | Flow Couplings | Visual, thread inspection | Re-dope, return to stock | Replace |
| 7 | Gauge Mandrel | Visual, thread, function | Re-dope | Replace |
| 8 | Packer | OEM inspection per vendor procedure | Redress per OEM | Replace |
| 9 | Control Lines | Visual, pressure test | Reuse | Replace |
| 10 | Plug / Prong | Visual, profile check | Reuse | Replace |

### 11.3 Cut & Re-Thread Coordination
1. Pre-identify a qualified threading workshop before mobilization.
2. Confirm workshop can handle: TPG2, HSM3, TPCQ-EX, N.Vam threads.
3. Confirm turnaround time.
4. Arrange transport between wellsite and workshop.

### 11.4 Pup Joint Fabrication
1. All completion tools (SSD, TRSV, check valve, drain valve, flow couplings) require pup joints to be made-up before running.
2. Pup joints must be:
   - Correct thread type.
   - New or re-threaded and inspected.
   - Drifted.
   - Pressure tested if applicable.

### 11.5 CCCP Fabrication
1. Cross Coupling Cable Protectors must be fabricated if not supplied by ESP vendor.
2. CCCP must fit:
   - 4-1/2" tubing coupling OD.
   - 3-1/2" tubing coupling OD.
3. Coordinate with fabrication workshop.
4. Quantity: ±130 for 4-1/2" + ±110 for 3-1/2" + spare.

## 14. CONTINGENCY PLANS

### 14.1 SSD Not Shifting
1. Redress tool and re-attempt.
2. Equalize pressure.
3. If fail → CT kill or bullhead with DME emulsion.

### 14.2 Packer Not Retrieving
1. Max approved over-pull.
2. Rotation if OEM allows.
3. E-backoff, pull free tubing.
4. Mill out packer.

> *If packer is permanent: **Set cement plug below packer before milling** to prevent debris from falling into well and damaging ESP pump.*

### 14.3 Cable IR Drop
1. Stop immediately.
2. Re-test.
3. If sustained drop → consult ESP vendor.
4. Do not continue with unacceptable IR.

### 14.4 Check Valve / Drain Valve Leak
1. Re-torque.
2. Re-test.
3. Replace with backup.

### 14.5 THS / THA Mismatch
1. Measure and compare with drawings.
2. If casing neck cutting needed → permit and execute.
3. If penetrator rod does not fit → send to WH manufacturer for machining.

### 14.6 7" Liner Lap Dry Test (Contingency)
If 7" liner lap integrity must be confirmed:

1. Set cement inside 7" liner below lap.
2. WOC.
3. Pressure test cement.
4. Set RTTS above 7" liner lap.
5. Test from above RTTS against cement.
6. This confirms liner lap seal.

### 14.7 Weather Delay
1. No splice in rain/humidity.
2. Heat/insulate test lines in cold weather.
3. Winterize rig systems.

### 14.8 Tong / Torque Gauge Failure
1. Switch to backup.
2. If backup fails → stop and request replacement.

### 14.9 Liner Lap Cannot Be Passed
1. Verify depth reference.
2. Apply 2-5 kips only.
3. Rotate 1/4 turn.
4. If no success → POOH and investigate.

### 14.10 Thread Damage on Retrieved Tubing
1. Separate damaged joints.
2. Send to cut & re-thread workshop.
3. If body OK → re-thread.
4. If body damaged → scrap.
5. Use new tubing if time-critical.

## 15. LESSONS LEARNED FROM PREVIOUS OPERATIONS

| # | Issue | Impact | Prevention |
|---|---|---|---|
| 1 | Casing tong + backup failed | >48 hrs NPT | Function test both before starting |

| 3 | Spooler shaft mismatch | NPT | Verify before mob |
| 4 | Shifting tool sheared | Multiple SL runs | Confirm profile + backup tools |
| 5 | THS profile mismatch | Casing neck cutting | Physical pre-fit at base |
| 6 | P-seal test port blocked | Could not test | Inspect all ports before shipment |
| 7 | XMT studs jammed/corroded | Had to cut studs | Anti-seize + verify alignment |
| 8 | Check/drain valve XOs leaked | Re-thread + replacement | Bench test before running |
| 9 | Wrong XOs from ESP vendor | Delay | Physical verification at base |
| 10 | Packer min ID smaller than plan | Potential restriction | Get full specs before acceptance |
| 11 | Hanger mark vs tie-down mismatch | Splice rework | Confirm orientation before splice |
| 12 | Lap depth discrepancy | Multiple verification runs | Calculate RTE correction |
| 13 | Poor ESP vendor crew performance | Multiple NPT | Audit vendor readiness |
| 14 | Shroud assembly table had no safety plate | Work stopped | Verify fixtures before mob |
| 15 | Test lines froze in cold weather | Delays | Insulate, heat, anti-freeze |
| 16 | Splice stopped due to rain | NPT | Enclosed splice shelter |
| 17 | H2S 600-800 ppm during flow | High risk | H2S service mandatory |
