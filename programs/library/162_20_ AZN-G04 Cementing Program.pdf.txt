I.WELL INFORMATION

1. Basic Data

         Well             Field          Client        Well Type            Job Type

     AZN-G04    South Azadegan  PEDEX   Development Well   Stab- in Cementing

2. Well Configuration

     Drilling Programme      Bit size  Well depth      Casing size Casing set depth     T.O.C

          First spud         26〞×156m            20〞×154m           Surface

3. Objective

  The 20″casing is designed to be set at 154m and cemented with stab-in method, the objective is

to provide shallow formation isolation and support for subsequent casing string.
4. Inner DP String Configuration

      5″Stab- in Stinger +5″ regular DP
