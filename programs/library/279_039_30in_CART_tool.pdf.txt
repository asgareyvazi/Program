TECHNICAL DESCRIPTION


Running Tool

   The lock/unlock mechanism of the tool consists of a right hand threaded stem
    (non-rising) and a mating cam sleeve. Five (5) turns of the stem to the left drives the cam
   sleeve downward approximately 2-1/2" and forces the ram dogs outward to engage and
   lock into the matching profile inside the wellhead housing. An indicator band on the OD
    of the stem aligns with the top edge of the cam sleeve when the tool is fully unlocked.
   Right hand rotation (5 turns) of the stem reverses the process.

   The tool is equipped with six 3" bull plugs. In cases where the conductor string is
   equipped with a standard float shoe or a cementing shoe, these plugs will be removed to
   enable total filling of the conductor string at the water line, after which they must be
    reinstalled and securely tightened. These plugs will be completely removed when
    jetting in the conductor string to provide unrestricted circulation and allow fluid returns.
  Some tools have one or two ball valves installed in place of bull plugs. In this case, the
   valve should be opened to allow the filling of the conductor string and then closed
   remotely.

30" Wellhead Housing

   The ID of the 30" housing has a double groove profile to accept the cam actuated
   running tool ram dogs. The lower ID of the housing accepts the elastomer seal on the
  cam tool. The lower OD lands inside the permanent guide structure and is oriented with
   a pin/slot interface inside the permanent guide structure center ring. The 30" housing is
   secured by a lock ring and/or retainer on the permanent guide structure. The upper OD
    of the housing includes a split latch ring for engagement with the 18-3/4" high pressure
   housing. The OD of the housing may include a seal which interfaces with the internal
   bore of the permanent guide structure, preventing hydrates from flowing by the housing
   and on to the top of the structure. Some 30" housings have anti-rotation discs in order to
    interface with older style guide structures. In the event that anti-rotation discs are
   present, the hydrate seal is not required.

ROUTINE OPERATION


                   PRE-OPERATIONAL CHECKS

30" Wellhead Housing

    1.    Install or inspect the o-ring on the OD of the housing, replacing it if required. Lightly
       grease the seal immediately before running the wellhead.

    2.  Inspect or install the anti-rotation discs, if required.

    3.  Inspect the ID of the split latch ring, ensuring the wickers are free of burrs and
         debris.

    4.  Inspect the cam tool profile, anti-rotation slot and seal bore on the ID of the
        housing. Lightly grease the ID of the housing.

Running Tool

    1.  Inspect the o-ring on the OD of the cam tool and replace if required. Lightly grease
        immediately before running the tool.

    2.  With the stem in the fully unlocked position and the ram dogs pushed back into the
         tool body, pump general purpose grease through the Alemite fittings until grease
        extrudes out the body vent holes or the ¼" relief check valve, if installed. The
       bottom fitting should be routinely used for grease injection to ensure proper and
        concentrated application of grease around the bearing.

    3.  Rotate the stem five (5) LH turns to extend the rams. Rotate the stem five (5) RH
        turns and ensure the rams will move back into the body freely when lightly tapped,
        using a wooden block and hammer. Reinstall the hex head plug.

    4.  Check the spring loaded anti-rotation (housing stop) pin on the cam tool to ensure
         that it moves in and out freely.





    5.    If the 30" conductor string is fitted with a float shoe or cement shoe and a stinger is
         to be run, remove the 3" bull plugs to completely fill the 30" casing with sea water
        before running. Replace and securely fasten all plugs after the casing is filled.


                             NOTE:


 Some tools may be fitted with one or more BALL VALVE assemblies in place of BULL
 PLUGS to facilitate venting of the casing.


    6.   Inspect the 3" bull plugs and ball valve assemblies (if applicable) and ensure that
        they are installed correctly and that the balls valves function correctly.

    7.  Later revision tools have incorporated two vent/wash ports located at 180o to each
        other between the ram windows of the main body. The vent holes communicate
        with each other through the annulus space above the bearing rings. Verify the vent
        holes are open. Grease will extrude from the hole during tool lubrication. A check

RUNNING PROCEDURE


     If the 30" conductor is to be jetted in, all 3" bull plugs must be removed from the running
    tool. The jetting string will be made up to the tool joint on the bottom of the running tool
   stem. With the running tool fully made up, the jetting sub should be spaced 12" to 24"
   above bottom, inside the conductor pipe, depending on the jet sub nozzle angle and
   bottom conditions.

Guide Structure and 30" Housing

    1.  Move the guide structure onto the spider/moonpool beams, orienting as required.

    2.  Make up and run the conductor string through the guide structure, using slings and
       padeyes or 30" casing elevators. If the operator determines that extra guidance is
        required for the conductor shoe to enter the Temporary Guide Base (TGB), this
       can be accomplished by welding half chain links to the conductor pipe just above
        the shoe. After the shoe is below the guide structure, soft line can be fitted between
        the links and guide lines.

Cam Actuated Running Tool (CART)

    3.    If not already done, rotate the tool stem of the cam actuated running tool to the right
       and push the rams back into the ram housing.

   4.   Position the running tool into the housing and carefully turn the tool by hand to the
        right until anti-rotation pins engage slots in the housing. Rotate the tool stem to the
          left, approximately five (5) turns, by hand, using chain tongs (nominal torque-500
         ft-lbs). The top of the cam sleeve should measure approximately 2-1/2" from the
        indicator band on the stem. Turn the tool stem back to the right, not more than 1/8
        of a turn to break any “seize” of the threads between the tool stem and ram
       housing.

   5.  Pick up the string and lower and land the 30" housing in the guide structure. Install
       the lock ring and lock ring retainer on to the guide structure. Paint a stripe on the
     CART and 30" housing (on the camera side) to affirm that tool has not backed out
       during jetting.

  6.  Commence running the 30" string. Using standard rig procedures, remove one
      or more bull plugs in the 30" cam tool. Lower the 30" assembly to the water
        line and completely  fill the string with seawater to prevent a possible
       hydro-static collapse condition. Reinstall and securely tighten the bull plugs. As
      mentioned one or more of the ball valves may be used to vent the casing.

   7.  Lower and land the Permanent Guide Structure (PGS) 30" housing assembly on to
       the Temporary Guide Base (TGB), or to the seabed if applicable, using the heave
      compensator. Lock the rotary. Unlock, at the desired height, above the block . DO
     NOT LET RUNNING STRING ROTATE. THIS MAY BACK OUT THE CART.


                           CAUTION:

Though it is desirable to maintain a wellhead angle at 0o - 1/2o, it has been Vetco
Gray’s experience that an angle of up to 1o can be safely drilled, making some
adjustments with rig position. Drilling can continue with the wellhead at a degree
greater than 1o; however, severe damage in the way of key seating by the drillpipe
throughout the entire length, from the casing immediately below the casing
hanger through the BOP into the first joint of riser about the flex/ball joint can be
encountered even though rig position has been corrected.


   8.  Cement as required.

   9.  When cementing operations are completed, adjust the heave compensator to
       support slightly more than the combined weight of the running string, running tool
      and cement stinger, if fitted.

  10.  Rotate the running string to the right approximately five (5) turns to release the
       running tool.

              POST-OPERATIONAL MAINTENANCE

 1.  Wash out the running tool thoroughly with fresh water.

 2.  Inspect the o-ring on the tool and replace if required.

 3.  Completely flush the tool, including circulating through the vent ports. Re-lubricate
     the tool before storage. Ensure that the vent plugs are fitted after flushing and
     greasing.

 4.    If the tool stem binds against the upper retaining ring, when retrieved, loosen the
    cap screws to relieve the bind, rotate the stem left hand and retighten the screws.

    The tool is designed to stretch the retaining ring cap screws and release at
     approximately 15,000 ft-lbs right hand torque, in the improbable condition of
      silt/sand preventing the cam sleeve from full travel. The cap screws should be
     inspected for looseness and replaced if higher torque is required to release the
      tool.

 5.  This tool should be stored in oil bath, and if so, equip the container with a drain to
    remove accumulated water.

 6.    If the tool is not stored in an oil bath protector, pack the external ram dog cavities
     with grease. Apply thread dope to the tool joint threads and install the thread
     protectors.

7.    Install 3" bull plugs and or ball valve assemblies (if applicable). Ensure correct
      installation and function prior to storage.

8.   Periodically remove the two pipe plugs in the lower tool body and pump grease into
     the lower bearing cavity. Ensure that the pipe plugs are re-fitted.
