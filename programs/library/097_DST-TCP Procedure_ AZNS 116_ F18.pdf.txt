DST/TCP Running procedure:

     Hold Pre-job Safety meeting prior to picking up DST/TCP tools
     Always install the slips and a safety clamps on the DST/TCP tool string before
       releasing them from the elevator.
     Under instructions and supervision of Sealand TCP & OEOC DST engineers, pick up
     DST/TCP tools and BHA.
     TCP guns no need any rig torque all with hand torque
     Pipe dope is applied only on pin end of the Tubing.
     Drifted Tubing with suitable rabbit (minimum 2”).
     Use only one rabbit at a time and ensure rabbit is out of pipe before making it up to
       string.
     String to be keep covered all the times.
     Do not use the rotary while RIH or POOH. No rotation to string.
     No Sealand equipment may be torque up or un-torque unless the Sealand engineer is
      present.
     Always stop the string before setting the slips. Do not throw the slips.
     Avoid any shocks to string while RIH. It can operate the tool prematurely
     Do not circulate or apply any pressure in the annulus or string unless DST/TCP
      engineer is present. (it can activate the DST/Firing Head prematurely
     ALL Equipment’s below the Pip tag shall be measure physically by the company
     man/DST/TCP BEFOR RIH.
     Ensure the running in speed NOT TO BE FASTER THAN 3 min per stand slip to slip
     Pick up TCP/DST tools horizontally using crane with two point connections and tag
       line.
     Transport tool to  drill floor & secure with tugger line (crane connections  still
      secured on back end of tool).
     Latch manual elevators on lifting sub and lower back end of tool with crane gently
      to rig floor.
     Unsecure tugger line and P/U on travelling block while lowering with crane (tool
      should never rest of drill floor).
     Untie back end connection to crane slings.
     Pickup tool with travelling block until make up height is reached.
     Make up all TCP Guns as per TCP Engineer
     Pick up and install firing head before connect FIRING HEAD NEED TO MAKE SURE NO
     BUDDY AROUND BELOW RIG FLOOR
     Pick up pipe joint and FIS and install above firing head
     Pick up x-over +1 stand drill pipe +x-over
     Pick up packer and DST BHA and Pip tag tools as per DST engineer instruction and
       string diagram
     String need to be filled manually with Diesel

                          DST-TCP

  Pressure test DST BHA above packer to below tester valve 5000psi 5 min
  Ensure that BOP rams are open. During Pressure test
   Drift tubular.
  Cover the tubular all the time.
  Slight dope at the pin end.
  Pressure Test BHA to 6k psi for 5 minutes minimum straight line.
  Bleed off pressure.
  Recommended to torque as per manufacturer’s requirement
  Ensure rams are open
  RIH each 1000m Drill pipe to be run in hole and do test
  Pressure Test Drill pipe and BHA for 5 minutes minimum straight line 5000PSI and
   (Do NOT OPEN ELEVAITOR DURING PRESURE TEST)
 BOP RAMS SHOULD BE OPEN DURING PRESSURE TEST
  RIH the remaining  Drill pipe. Pressure Test  Drill pipe and BHA for 5 minutes
   minimum straight line 5000PSI and (Do NOT OPEN ELEVAITOR DURING PRESURE TEST)
  Ensure rams are open.
  RU GR/CCL and perform correlation.
  Record and confirm with TDDC witness the amount of off set.
  POOH with GR/CCL.
  POOH Drill pipe for space out
  TDDC representative to advice space out to be confirmed by TCP/ DST specialist.
  Adjust space out of string – Add / Subtract pup joints accordingly
  Make up flow head or flow line
  RIH to packer setting depth.
  Record string weight RIH, go past packer setting depth according to DST specialists
   instructions
  Pick up string to packer setting depth
  Record string weight up.
  Set slips.
  After set packer test 500psi 5min for test packer
  Apply 1200psi to open TEST VALVE
  Apply 3900-5500psi in tubbing to fire the gun

Note:
   o   All data should be recalculate based on actual based on well site.
   o  Correlation and Space out will calculate after getting actual information on the wellsite
      and confirmed with Company man/ Client rep, DST and TCP Engineers.

Job Plan
Tubing Conveyed Underbalance Perforation is working with Hydraulic Pressure Activated
Firing System to perforate well AZNS-116, perforation1 Run and four HSD guns will be used
to perform the job.

   2. Firing Head
Firing Head assembly need witness by Co-man. Install totally 13 Shear Pins of each 906psi.
RIH Firing Head in open System, so annulus Pressure acting on Firing Head while RIH.
However, to consider the worst case, while Shear Pin Calculations, Annulus Fluid Acting on
Firing Head was considered while RIH.
Fire head depth: 3895m

Shear Pin Calculation.
As report by TDDC
Annulus Fluid: 105pcf          Annulus Pressure @Firing Head Depth = 9312psi
Cushion Fluid: 80pcf           Cushion Pressure @Firing Head Depth = 7099psi

Safety Margin Pressure = P safety margin = 1000psi

Total Operating Pressure for Firing Head is = P annulus + P safety margin = 9312 + 1000 = 10312
psi.

Installed Shear Pin Pressure = 13 * 906 = 11778psi
True Safety Margin =1466psi
Surface Apply Pressure = 4400-4600psi

Underbalance pressure:
9270psi Reservoir pressure - (7099psi cushion pressure+ 468psi Rat hole) = 1703psi
underbalance pressure
