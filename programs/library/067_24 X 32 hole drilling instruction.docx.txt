24” X 32” Hole Section Drilling Action plan
Daily instruction, 2017-Jul-23, Rev.0
BHA
24” Milled tooth bit ( IADC Code: 111, Dressed w/ 3* 12/32” Nozzles, Plugged center jet)
24” x 32” Hole opener ( Dressed w/ 12/32” Nozzles @ 32” stage, Plugged 24” stage)
9-1/2” Bit sub ( with baffle plate)
1 Std 11” Drill collar
2 Stds 9-1/2” Drill collar
XOS ( 7-5/8” Reg x 6-5/8” Reg)
1 Std 8-1/2” Drill collar
XOS ( 6-5/8” Reg x XT57)
1 Stds 5-7/8” HWDP
5-7/8” Drill pipe
Drilling Program
Drill ahead formation down to ±150 m (26” Casing point in Aghajari formation).
Drilling from 12-17m
WOB: 0-5 klb, RPM: 30-50
FR: 200-300 gpm
Drilling 17-22 m
WOB: 0-5 klb, RPM: 40- 60,
FR: In steps of 300 gpm up to 500 gpm
Do not back ream the first 10 m.
Drilling 22-32 m
WOB: 0-7 klb, RPM: 40-60,
FR: In steps of 500 gpm up to 900 gpm.
Drilling 32-150 m
WOB: Maximum available
RPM: 60-80, back reaming: 60 rpm.
FR: 900- 1100 gpm.
Drilling plan
M/U 24"bit (Bit#1, IADC: 111) and 24” x 32"hole opener. P/U BHA. Tag ground.
Drill 32" hole from 14 m to 60 m.
Circ clean hole. Run Tatco. Pull out Tatco to surface. Run back in to BTM.
Cont. Drilling 32" hole from 60 m to 110 m.
Circ clean hole. Run Tatco. Pull out Tatco to surface. Run back in to BTM.
Cont. Drilling 32" hole from 110 m to ±150 m - section TD.
Condition hole prior to run casing. Spot high viscosity pill at bottom, Drop Tatco. POOH.
Change TDS links. R/U 26" CSG running EQP.
In case of any deviation from vertical (based on Tatco result), adjust drilling parameters to drop the angle and return to vertical, such as decreasing WOB, controlling ROP, increasing FR, etc.
Use LCM pill if heavy loss is encountered. If loss couldn’t be cured by LCM pill, use cement plug(s) to cure it.
During trips, at surface, driller is responsible to check BHA.
Perform hole condition prior to run casing. If any indication of drag is observed, run back to bottom. Wash and ream to make sure that the hole condition is good.
In case of Bit balled up, Before POOH, Drop Tatco.
After each joint Kelly down, Circ BTM’S Up.
Note1: In case of plan change, the revised instruction would be sent to you ASAP.
Note2: Don’t hesitate to contact DSV in order to clear any problem.
Note3: The revised or added items are highlighted in new instructions.
Good Luck & Be safe.
