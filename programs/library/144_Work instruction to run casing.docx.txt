Work instruction to Run 20*18-5/8”CSG
To:  Toolpusher, mud engineer, mud logger, waste management, Sarvak Kish Rep. & SAED Rep.,
Make Rig floor clear of any unnecessary equipments, Rig up 20”casing running equipment
Pre job safety meeting with all key personal includes: safety officer, Rig manager, Toolpusher, rig floor crow.
Visually check every joint pin & Coupling before make up them. Apply casing dope on joint coupling.
Bring the XOS 20” to 18 5/8”, 18 5/8” swage, 20”centralizer and 20”Stop collars and Pins for Stop collars, bakerlok.
Bring fist joint of 20”casing already makeup by float shoe to the rig floor,
Pickup and makeup total 4 joint 20”csg above shoe ( shoe track is 4 joints 20”csg ).
Makeup 20” float collar( use bakerlok on box section of float collar ) and 1 joint 20”csg above it, install XOS ( 20” * 18 5/8”) and 18 5/8” swage, circulation as string volume, check mud return.
Continue run 20”csg as per csg tally, switch to 20” spider slips and elevator by approaching 120K lbs on weight indicator.
Use 20” * 24” centralizer on the first and third joint above shoe ( shoe track ) and 1 joint above float collar, continue use Bow centralizer each 6 joint and csg runing ahead, the last 2 centralizer which is used should be 18 5/8” * 30”.
Fill up string with mud each 5 joints to +1600m.the last +380m of csg string will be Unfilled.
Makeup XOS ( 20” * 18 5/8”), for making up this XOS call the company man to the rig floor.
Continue run 18 5/8” csg ( 136ppf, 114ppf consequently ) as per tally to the bottom.
After approaching to the Bottom rig up CMT head and CMT line.
