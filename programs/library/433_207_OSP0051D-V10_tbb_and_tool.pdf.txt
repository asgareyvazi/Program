TECHNICAL TOOL DESCRIPTION


Temporary Guide Base

   The Temporary Guide Base is a foundation structure with approximately 100 square
    feet of bottom surface area. The guide base has a center well fitted with J-slots which
   require left-hand rotation to engage. The guide base provides preliminary guidance for
   subsea drilling operations, an anchor point for guidelines, or can be fitted with sonar
    reflectors and guidance beacons for guideline less operations. The temporary guide
   base funnel allows for compensation of bottom slope up to approximately five degrees.


                             NOTE:


  If the conductor pipe, conductor housing, and permanent guide structure is jetted into
 place, it is not necessary to use the temporary guide base


Running Tool

   The temporary guide base running tool consists of a long tool stem with a cylindrical
   body fitted with external lugs which jay into (lock in) the temporary guide base center
    well. The tool is equipped with a ball and socket to provide some freedom of movement
   between the running string and tool to compensate for minor bottom slope.

               TEMPORARY GUIDE BASE AND RUNNING TOOL

ROUTINE OPERATIONS


                   PRE-OPERATIONAL CHECKS

Temporary Guide Base

    1.  Weld the guide base legs to the temporary guide base. This applies only if the base
       has been shipped without these legs attached because of storage problems.

    2.     If temporary guide base has been previously run, inspect the J-slots for damage or
        burrs and re-dress using a grinder. Check for fit and function by making up the
        running tool. Lightly grease the J-slot area.

    3.     If required, install the television guide frame.



Running Tool

        Inspect dogs for damage or burrs, re-dressing as necessary. Apply heavy grease
       between the ball and the cover plate.

POST-OPERATIONAL MAINTENANCE


Temporary Guide Base

   None required.

Running Tool

    1.  Wash with fresh water and apply a light coat of grease to the drillpipe box and
          install thread protector.

    2.  Remove the socket head cap screws that secure the cover plate, and remove the
        cover plate. Lift the stem and ball out of the body of the tool. Clean and thoroughly
      wash all parts and apply a coating of heavy grease to all surfaces. Re-assemble
        the tool. Use only a little grease on the socket head cap screws.
