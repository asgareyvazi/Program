         COMPLETION STRING PROGRAM

                «NAR-19 / RIG 84 FA»


  Important Note:
   Well is under complete loss. While running completion string from surface to the
   packer setting depth, fill up annulus by fresh water at a safe rate as experienced in
   the previous killing and cleaning operations. Fill up tubing but all the time leave
   about 500m of the tubing empty to avoid premature set of packer.

   Prior to set packer start filling up with corrosion inhibited completion fluid. Fill up
   the annulus after setting packer till got level at surface.


A-Completion Surface Tests:
     1.  Drift and measure OD, ID and length of all completion accessories.

     2.  Set dummy in 3SV L/nipple, connect Control line and test against dummy to
       5000 psi.

     3.  Set plug in no-go L/nipple and test to 4500 psi, leave the plug set. (Check it to be
        retrievable).

     4. Open Traveling Joint fully and test to 4500 psi, set shear pins.

     5. Perform surface test of SPM & SSD.


B-Completion Running Procedure:

          •  Remove wear bushing.
          •  Rig up completion running tools.

     1. RIH as per attached tally (with plug in no-go L/nipple) up to 3SV L/nipple.

    Note: Fill up 100m on top of no-go plug with Hi-Vis corrosion inhibited polymer pill
    (≥120sec) and the rest joints by corrosion inhibited gas oil.

 2. Connect control line to 3SV L/nipple and test to 4500 psi against dummy. Band
    control line straps to tighten same against tubing.

 3.  Continue RIH as per tally, Pick up tubing hanger, Connect Control line to same
   and test to 4500 psi.

 4. P/U 7” Landing joint, connect to tubing hanger.

 5. R/U Pump unit.


 6.  Flush and clean tubing head spool with water (or by air).

 7. Land tubing hanger and just touch tubing head spool.

 8. Space out and pull out the string 3m up (for total stroke of 20ft).

 9.  Pressurize tubing to 4500 psi step by step (500 psi on each step @ 3 min.)and
    monitor tubing anulus at same time (open tubing head spool side outlets).

Note: While pressurizing inside tubing to set packer, If the well static, some back
flow will be observed through tubing head spool side outlet valves, it should be
stopped after a while.

 10. Release pressure and over pull the string with 20,000 lb's.

 11. Apply proper weight down ward to shear off expansion joint shear pins, then set
    tubing hanger at its position in tubing head spool.

 12. Tighten tie down screws.

 13. Test inside tubing to 4500psi (15 min), close top rams and test Hanger to 4500
     psi.

 14. Test annulus to 2000 psi (15 min), and back off Landing Joint.

 15. Set two-way check valve inside tubing hanger. Pressure test to 4500 psi (15min).

 16. N/D BOP's.

 17. Check hanger for any damages. Pressure test control line to 4500 psi against
   3SV dummy.

 18. Nipple up wellhead as per program. Pressure test same.

 19. Pull out two way check valve.

20. Connect flow line and chock manifold to the X-mas Tree, R/U wire line
   equipment and lubricator. Test wellhead, chock manifold and flow line and wire
    line equipment to 4500psi.

21. Remove prong and plug from no go nipple.

22. Flow the well through variable choke sizes to clean up the well.


23. Having cleaned the well, record the flowing pressures on different choke sizes
   and burning line pressure at the same time.

24. Close the well.

25. Remove dummy.

26. Flush control line with hydraulic oil.

27. Install 3SV and test control line to 4500psi.

28. Release above SSSV pressure to zero.

29. Monitor wellhead pressure for any 3SV leakage.

30. Fill up above 3SV with completion fluid.

31. Close all valves except bottom master valve and 2SV.

32. Release Rig.
