        COMPLETION STRING PROGRAM

            «PYW # 10 / RIG OOK2»



   Important Note: Prior to L/D drill pipes displace mud in hole by corrosion
    inhibited gas oil.

A-Completion Surface Tests:
     1.  Drift and measure OD, ID and length of all completion accessories.

     2.  Set dummy in 3SV L/nipple, connect Control line and test against
     dummy to 5000 psi.

     3.  Set plug in no-go L/nipple and test to 4500 psi, leave the plug set. (Check
           it to be retrievable).

     4. Open Expansion Joint fully and test to 4500 psi, set shear pins.


B-Completion Running Procedure:

          •  Remove wear bushing.
          •  Rig up completion running tools.

     1. RIH with Mule shoe_Top no-go L.Nipple and…...etc. as per attached
         tally (with plug in no-go L/nipple) up to 3SV L/nipple.

    Note: Fill up 100m on top of no-go plug with Hi-Vis corrosion inhibited
   polymer pill (≥120sec) and the rest joints by corrosion inhibited gas oil.

     2. Connect control line to 3SV L/nipple and test to 5000 psi against dummy.
      Band control line straps to tighten same against tubing.

     3.  Continue RIH as per tally, Pick up tubing hanger, Connect Control line
        to same and test to 5000 psi.

     4. P/U 7” Landing joint, connect to tubing hanger.

     5. R/U Pump unit.

 6.  Flush and clean tubing head spool with water (or by air).

 7. Land tubing hanger and just touch tubing head spool.

 8. Space out and pull out the string 3m up (for total stroke of 20ft).

 9.  Pressurize tubing to 500 psi (3 min), 1000 psi (3 min), 1500 psi (3 min),
   2000 psi (3 min), 3000 psi (15 min) and monitor tubing anulus at same
    time (open tubing head spool side outlets).

Note: While pressurizing inside tubing, some back flow will be observed
through tubing head spool side outlet valves, it should be stopped after a
while.

 10. Release pressure and over pull the string with 20,000 lb's.

 11. Apply proper weight down ward to shear off expansion joint shear pins,
    then set tubing hanger at its position in tubing head spool.

 12. Tighten tie down screws.

 13. Test inside tubing to 4500psi (15 min), close top rams and test Hanger to
   4500 psi.

 14. Test annulus to 2000 psi (15 min), and back off Landing Joint.

 15. Set two-way check valve inside tubing hanger. Pressure test to 4500 psi
    (15min).

 16. N/D BOP's.

 17. Check hanger for any damages. Pressure test control line to 5000 psi
    against 3SV dummy.

 18. Nipple up wellhead as per program. Pressure test same.

 19. Pull out two way check valve.

 20. Connect flow line and chock manifold to the X-mas Tree, R/U wire line
   equipment and lubricator. Test wellhead, chock manifold and flow line
   and wire line equipment to 4500psi

 21. Remove prong and plug from no go nipple.

 22. Remove dummy and flush control line.

 23. Install 3SV and test control line to 5000 psi. If OK, release control line
    pressure to close 3SV. R/D wire line equipment.
