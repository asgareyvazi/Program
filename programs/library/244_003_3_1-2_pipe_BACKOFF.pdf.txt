Back Off Procedures 3 ½ Pipe




1.    Ensure String has been correctly torqued to the right with circa. 9900 foot pounds


2.    From Recorded String Wts, Up 170 k, Down 135 k, Rot circa. 150 k


3.    With the slips set at 200k, work in 3-4 LH turns, pull slips and work pipe from 120k
     Down to 250k Up. Ensure a tong line sensor is connected to the rig tong holding the
      back off torque so that transmission of torque can be visually observed.


     Once the torque has dissipated down hole, set slips at 200 k.


4.    With the slips set at 200k, work in 2 LH turns, pull slips and work pipe from 135k
     Down to 250k Up. Checking on load cell to ensure torque is being transmitted
      downhole.


      Continue to work torque down in 2 turn stages until 8-9,000 ft/lbs approx 7-8 LH
turns  are in the string.


5.    Once satisfied that the torque has been fully transmitted down hole, hold string wt
at    170 k until string shot is in place. Before charge is fired, correlate depth relevant to
      chosen connection (preferably one which was broken on previous trip) and fire
charge.


6.        If the back off is complete, correlate CCL to confirm backoff point.

7.         If no positive indication the pipe has backed off, Pooh with wireline, then continue to
       work pipe across neutral point to complete back off.


8.     Once back off is complete evaluate whether to return with a screw in jarring
  assembly  or if desired and sufficient window is available below casing shoe a side track
   option    may be a better alternative.
