
1/ Pick up Isolation test tool to rig floor.
2/ Run 3 x stands of drill pipe and a jet sub bellow the ITT.
3/ Make up x/over sub from 5´´ pin to 3 ½´´ IF box to accommodate the pin of the ITT. (3 ½´´IF)
4/ Make up the ITT to the x/over with 17000ft/lbs to 20000ft/lbs of torque.
5/ Make up stand above ITT to 28,000ft/lbs of torque and 5 ½´´ to 35,000ft/lbs (ITT box 4 ½´´ IF)
6/ Ensure that the ITT is positioned in the long slot for testing against the NSP (Nominal Seat Protector)
*NOTE* under no circumstances must the ITT be run in the short slot when NSP is in hole, this could result in collapse of the NSP in the high pressure wellhead. Also: Never run test plugs in hole when the NSP is installed in the wellhead, again this could cause the NSP to collapse.
7/ When ITT is made up to string, Prior to locking tool in safe mode to run in hole, pull the slips and set the ITT into the insert bushings. Slack off slowly until the lock ring is felt starting to expand. Stop as soon as it is felt by hand and pick back up. Reset the slips and turn the body of the ITT to the right with a chain tong ¾ of a turn until the body stops turning. This puts the ITT in the lock position until landed in the high pressure wellhead.
8/ Pull the slips and insert bushings taking care when going through the rotary with the ITT.
9/ Just above the BOP with the ITT, open the compensator to prevent any hang up in the BOP with the ITT.
10/ Land the ITT in the HPWH and take an index measurement with 10,000lbs set down on the ITT.
11/ Turn the string to right until a drop in the string of 3 ½´´ is observed by using the index measurement again.
12/ Set down 20,000lbs of string weight at this point. This engages the lock ring of the ITT to the H-4 profile of the high pressure wellhead bore.
13/ All BOP tests can now be done to a maximum of 15,000psi.
14/ When all tests completed, Ensure all rams are open and pick strait up on string, observing for any over pull. There should be none or very little over pull to collapse the lock ring on the ITT.
15/ When the ITT come out of hole. Wash with fresh water and inspect for any damage. Grease and protect the bulk seal on the main body.
