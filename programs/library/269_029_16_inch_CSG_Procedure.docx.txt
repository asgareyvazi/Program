
16” CSG SECTION PROCEDURE
Goldfinger
OFFLINE OPPORTUNITY:
Plug in at rotary and down load MWD while racked back in derrick.
POOH drop Rabbit (2.875” hollow). P/U single of DP to rack 9.5” DC back in derrick. L/D centurion sub & 17” stabilizer, rack the rest of assembly in derrick.
R/U Weatherford CSG equipment.
Stab master use safety sling if no locks.
CSG tongs are not mechanized so this needs to be addressed at PJSM.
Mix HALCO spacer 130-bbl at 15-ppg in add #2 pit.
P/U 16” shoe track.
Look inside FC/FS joints for trash.
Run 1-baker lock joint between FS & FC as per tally.
CSG is auto fill. (Monitor returns & visually verify filling)
1-14 out/#24 out for a total of 15 joints of CSG left on deck.
M/U FMC Hanger assembly lower thru rotary table & L/D handling tools.
TIH W/16” CSG on 24.7# DP. Install a single of DP above hanger. Install Allemon Diverter tool 3-stands above hanger.
Drop 2.25” brass ball after hanger passes thru wellhead.
Land out 16” on profile.
Close Allemon tool W/+ 2500-psi.
Float equipment will close @ 5-8 BPM.
If bridge encountered do not set more than 30K DN wash thru bridge.
Pump spacer & CMT (700’ of CMT coverage 10% excess) as per HALCO.
Kick top dart out with HALCO @ 10-bbl.
Leave HALCO rigged up for data recording.
Displace with rig pumps @ + 15 BPM. Bump plug W/500-psi over pump pressure.
Darts thru Allemon @ + 2200/3000-psi.
Shear wiper plugs W/+ 2400-psi.
HALCO to check floats.
Set 16” pack-off as per FMC. P/U off 16” (NO PULL).
Rotate to right 4-rounds W/15 K DN.
Set 35K DN to pressure up on backside to 1500-psi W/HALCO, after running tool released. (Test offline)
If returns present during CMT job. Circulate out after bumping plug.
POOH if plugs bumped, test CSG to 250-psi 5-minutes / 700-psi 30-minutes (test to be performed out of critical path.
L/D running tool. P/U BHA & TIH.
