Make sure annular valve on casing head housing is open free from VR plug.
Remove flapper on kill line check valve.
Conduct function test all bop stack.
Pick up & land test plug on housing. For first time Aker man should be witness on rig floor while landing test plug. Prior to landing grease plug properly.
Fill up stack with sea water.
Line up cement unit to drill pipe Flash & pressure test unit & surface line to 3000 psi.
Close annular, close outer side outlets, open inner outlets & pressure test to 500/1500 psi for 5/10 min. Make sure that kill & choke line are exposed to atmosphere. (Test #1)Release pressure through unit.
Open annular, close inner outlets, open outer outlets, close pipe rams & pressure test to 500/1500 for 5/10 min. Release pressure.
Back off drill pipe from test plug, pull out joints to surface, install flapper on kill line check valve, open outlets on kill line, connect cement unit to choke line, pressure test blind rams & check valve to 500/1500 for 5/10 min. Release pressure.
Open blind rams, run back joints, retrieve test plug.
Install wear bushing, close side outlets on casing head housing.
Record all tests in cement unit.
