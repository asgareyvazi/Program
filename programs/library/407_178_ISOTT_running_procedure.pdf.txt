Objectives: Running Isolation Test Tool (ISOTT), Connector test, Function test,
Accumulator test, Diverter test, Shallow gas procedure
    1.  Remove spider, install bushing.

    2.  Hold PJSM . Well head engineer (Gus)will be man in charge.

    3.  Make up the ISOTT to a stand of drill pipe ensure the stem does not turn relative to the body(ensure
      The tool has a 3 1/8 “gap between the upper and lower sections). “NOTE” if the C-ring does not expand
       ANTI ROTATION PIN IS IN WRONG POSITION .

       *** ROV requested: we will set down 117 ton BOP wt. on well head(check 30” Conductor pipe)

    4.  Pick up on string and reset tool LH to run by rotating stem 284 Deg against stop (NO TORQUE SHOULD BE
       SEEN)

    5.  Check status of inner polypack seal

    6.  Grease tool prior to running .

    7.  RIH with following string: (don’t forget to put diverter insert packer)

           -    Jet sub(rubber bull nose )

           -   XOS 4-1/2” IF pin x 5-1/2” FH box

           -   12 jts 5-1/2” HWDP

           -   XOS 5-1/2” FH pin x 3-1/2” IF box

           -   ISOTT

           -   XOS 4-1/2” IF pin x 5-1/2” FH box

           -   1 std. 5-1/2” 38.01 ppf landing string.

           -   24 std. 5-1/2” 21.9 ppf landing string

     NOTE: Collapse pressure of landing string is 31,798psi and the (21.90 lbs/ft has a collaps

       pressure of 12,679psi) and we don’t want to collapse this drill pipe. So we require to use the 38.01

         lbs/ft.

    8.  Float Compensator, open Choke and Kill lines PRIOR TO ENTERING STACK AND THEN RUN SLOWLY TO
      LAND OUT.

    9.   Set 10-15k of weight down (max 40klbs) and close choke and kill Check reference line and open string to
       atmosphere(in case for checking leakage)

    10. Rotate the string 284 deg. Clockwise (MAX TORQUE 3-5000 ft.lbs) and Check string closes 3 1/8” against
         ref. line. As the string drops increase weight down to 20k-60k max  Assists in setting tool.

    11. Ensure string is full and open to atmosphere.

    12. Test BOP with 500 psi low pressure 5 min, then increase in increments of 1000psi steps to 14000 psi(up
        to 10000 psi by cementing unit) having tested against the valve line we are going down.

    13. Complete function test/Accumulator test (draw down test) as DNV & Cameron procedure. Record
       volumes & closing/opening times carefully. Shear rams will test after string pulled out.

    14. RECOVER ISOTT AFTER TESTING. PICK TOOL STRAIGHT/EASY UP OUT OF WELLHEAD.

    15. Test diverter & flow line up to 500 psi.

    16. Perform shallow gas exercise. All personnel shall participate in this exercise. Make sure everybody
       understand their duties and brief review after exercise.
    17. Mixing bentonite sweep pill/kill mud/Kcl-polymer mud ongoing in pit room as per MI Mud Engineer
      program ASAP.(all mud pit dump valve seals to be checked prior to filling pit up with water). MSDS
        shall be reviewed before mixing mud.
    18. Shaker screen shall be requested by OIM as per MI Mud Eng. Request ASAP.
