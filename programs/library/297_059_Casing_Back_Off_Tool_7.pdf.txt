                      7" CASING BACK-OFF PROCEDURES


1    Make up 7" Casing Cutting Assembly. Test the cutter at surface.
     Run in the hole and make the cut in the 7" approximately 5 feet below the collar in first joint
      above the joint that is required to be backed off.

      5 9/16" Pipe Cutter Assembly

       6" Taper Mill                         3 1/2" Reg Pin
      5 9/16" Pipe cutter                     3 1/2" If Box x 3 1/2" Reg Box
       Dressed with 7" Casing Knives
       6" String Stabiliser                     3 1/2" IF Pin x Box
      3 1/2" Drill Pipe                       3 1/2" IF Pin x Box


2    Run the Spear Assembly and recover the cut section of 7" Casing.

       7" Spear Assembly

       7" Pack off Tool                       3 1/2" IF Box x Bullnose
       7" Casing Spear                       3 1/2" IF Pin x 4 1/2" IF Box
      c/w 6.095" Nominal Catch Grapple
      6 1/2" Bumper Sub                     4 1/2" IF Pin x Box
      3 x 6 1/2" OD Drill Collars              4 1/2" IF Pin x Box


3    Run the Casing Dressing Assembly and dress / mill off the casing top.

      Casing Dressing Assembly

      8 1/4" OD Casing Dressing Mill          4 1/2" Reg Pin
      c/w 6" OD Pilot Mill
      X-Over                              4 1/2" Reg Box x 4 1/2" If Box
      3 x 6 1/2" OD Drill Collars              4 1/2" IF Box x Pin
       5" Drill Pipe to surface

       Mill off 4"-6" then circulate bottoms up and pull out of the hole.

4    Make up the 5 5/8" OD Casing Back-Off Assembly.

      Casing Back-Off Assembly

      5 3/4" OD Bullnose                         3 1/2" If Box
      5 5/8" Casing Bottom Anchor Section          3 1/2" If Box x Pin
      5 5/8" OD Lubricated Slack Joint              3 1/2" If Box x Pin
      5 5/8" OD Torque Generator Section           3 1/2" If Box x Pin
      5 5/8" OD Clutch Unit                      3 1/2" If Box x Pin
      5 5/8" Casing Top Anchor Section             3 1/2" If Box x Pin
      Swivel Joint with landing shoulder             3 1/2" If Box x Pin
      5 5/8" OD Slack Joint                       3 1/2" If Box x Pin
      By-Pass Valve                             3 1/2" If Box x Pin
       Circulating sub                            3 1/2" If Box x Pin
       Crossover sub                             3 1/2" If Pin x 4 1/2" IF Box
       5" OD Drill pipe to surface


5.    Run in the hole with the Casing Back-off Assembly.

6     Record the string parameters before entering into the casing stump.
      Lower the assembly into the casing until the landing shoulder is resting on the top of the
       stump. Continue to slack off until the upper slack joint has closed and then apply 20,000 lbs of
       weight on the stump.

7      Pick up the string to put the upper slack joint in mid-stroke leaving the weight of the back-off
      assembly (7,500 lbs) resting on the landing shoulder.

     Make Sure Blocks Are Unlocked for Work String to Be Free to Rotate While Suspended
       in the Elevators. This is a precautionary measure as no rotation should be seen at surface
      due to the Swivel Sub in the tool.

8       Initiate the back-off sequence by bringing in the pumps up to 150-200 Gpm. This will close the
       by-pass valve and allow pressure to be exerted on the anchor sections and torque generator. As
       the pressure increases (Max 5000 psi) breakout of the connection should begin, this may be
       noticed by a fall off in pressure as the connection breaks. At the end of one cycle (1/2 a turn)
       the pressure will increase indicating the end of the tool stroke. Hold pressure for 5 minutes.

9     Bleed off the pressure to zero. As this is done the tool will reset itself in preparation for the
       next torque cycle.

10     Restart the pump and increase the pressure again to activate the torque generator. The pressure
      peak on this cycle should be less than on the previous cycle, however pressure up to 5000 psi
        regardless, as less force will be required to unscrew the connection after the initial breakout.
       Repeat the cycling procedure until eight cycles have been achieved. At this point four full turns
       should have been applied to the casing connection.

11    Drop the circulating sub ball and open the circulating sub with 1500 psi. POOH.

12    Run back in the hole with a standard 7" Spear Assembly, engage the casing stump and
       complete the back-off sequence. Recover the casing to surface.

       7" Casing spear                            4 1/2" If Box x 3 1/2" If Pin.
      c/w 6.095" Nom grapple
      6 1/2" OD Bumper Sub                      4 1/2" If Box x Pin
      6 x 6 1/2" OD Drill Collars                   4 1/2" IF Box x Pin
       5" OD Drill Pipe to surface

13      If remaining casing is pin up, make up 7" Casing Alignment Tool (special manufacture) onto
       the first joint of casing and run new casing string.

Note:  Brushing tool may be utilised to clean inside box up if deemed necessary.
     An internal guide assembly will be used if casing is box up and can be stripped in to aid in
       connection alignment and make-up. New casing string must have 2 feet long pup joint as first
         joint.

14    As alignment tool reaches the top of the connection it may require slight RH rotation of string
        to put alignment tool over the casing.

15    Continue with RH rotation until the connection is full made up. POOH with internal guide
      assembly if run.

16     Pull casing into tension and set slip and seal assembly with the desired weight.

17     Pressure test as required.
