1. SCOPE AND OBJECTIVE
1.1 Scope
This document covers the complete workover operation to:
Kill the existing well using emulsion fluid (DME-based low-density fluid).
Retrieve the existing completion string.
Perform corrosion logging on casing strings.
Inspect, redress, and re-certify all retrieved completion tools.
Replace / modify the Tubing Head Spool (THS) for ESP configuration, including cement and RTTS operations.
Perform hole cleaning, scraping, and drift verification.
Run new ESP completion string including all downhole and surface equipment.
Perform ESP cable splice to tubing hanger penetrator.
Land tubing hanger in THS.
Install tubing head adapter (with penetrator rod and exit blocks for TRSV CL and AGV CL) and X-mas tree.
Conduct ESP pilot test and well performance test.
Secure the well and release the rig.
1.2 Objective
Successfully install and commission ESP completion.
Zero HSE incidents.
Minimize NPT through thorough pre-job planning and readiness.
Document all test results, hold points, and handover data.
Ensure all retrieved tools are inspected and either redressed or replaced for future use.
1.3 Key Notes
No landing nipple is required in the ESP completion design.
The tubing head adapter must have two exit blocks: one for TRSV control line, one for AGV control line.
The penetrator rod on the tubing head adapter must be checked and verified before mobilization. If modification or machining is needed, coordinate with wellhead manufacturer in advance.
A complete set of ESP-type THS/THA/XMT should be available as ready-to-install inventory, or pre-ordered and modified by the wellhead manufacturer.
All completion tools (SSD, TRSV, XOs, pup joints) are to be provided by the contractor, not the ESP pump supplier. The pump supplier provides only: ESP pump, motor, protector, intake, gas separator, sensor, shrouds, centralizer, cable, MLE, BOD, sub pressure, and packer with accessories.
Before running, tubing head adapter penetrator rod must be physically checked through the adapter. If machining or re-threading is required, coordinate with the wellhead manufacturer before mobilization.

5.7 Fluids and Chemicals
DME Emulsion Mixing Procedure:
Prepare required volume of fresh water in reserve pit.
Add diesel at specified ratio.
Add DME emulsifier additive as per chemical supplier recommendation.
Mix thoroughly to form stable emulsion.
Measure and confirm fluid weight is at target (lower than formation pressure gradient to avoid losses).
The purpose is to kill the well without causing losses by keeping hydrostatic pressure below fracture pressure.

8. DETAILED EXECUTION PROCEDURE – PHASE BY PHASE
Phase 1: Rig-Up and Preparation
Estimated Duration: 48 hours (2 days)
1.1 Rig Move and Rig-Up
Move rig to well location.
Level rig. Confirm level before any operation.
Rig-up all systems.
1.2 Measurements and Reference Points
Measure and record:
RT elevation from ground level.
THS elevation from ground level.
RT to THS Tie-down Screw distance (landing reference).
Wellhead orientation / north reference.
Confirm these match program depths. Calculate and document any RTE correction.
1.3 Stand Back Equipment
Stand back 5" DP, 3-1/2" DP, 2-7/8" DP (HT PAC).
Rack 4-3/4" DC, 3-1/8" DC, 3-1/2" HWDP.
All tubulars to be washed, drifted, and measured before use.
1.4 Line-Up
Line up mud pump / pump truck to kill valve.
Line up flow line to choke manifold.
Line up THS side outlet to choke manifold if applicable.
Pressure test all surface lines.
1.5 Wellhead Survey
Record all wellhead pressures (tubing, all annuli).
Bleed each section carefully.
Record pressure vs time, fluid type, volume, gas/H2S.
Fill annulus if empty.
1.6 Pre-Job Safety Meeting
Conduct rig-level safety meeting covering scope, H2S hazards, emergency procedures, roles, BOP drill, communication.
Phase 2: Kill the Well
Estimated Duration: 12–28 hours
2.1 Kill Method Priority
Primary: Reverse circulation through SSD using DME emulsion fluid.
Secondary: Coil Tubing kill (if provided by Client as extra work).
Tertiary: Bullhead kill.
Note: DME emulsion fluid is used to reduce hydrostatic weight and avoid losses during kill operation. The emulsion is mixed by adding DME additive to water and diesel.
2.2 Slickline Operations for Kill Preparation
Rig up slickline equipment and BOP.
Pressure test SL BOP: 2500 psi.
Install TRSV protection sleeve if applicable.
Run gauge ring to 2m above guide shoe. POOH.
Set 2.562" RPT plug in No-Go landing nipple. POOH.
Set prong inside plug. POOH.
Shift SSD open using 2.750" shifting tool. POOH.
If SSD opens successfully, rig down slickline.
2.3 SSD Shifting Contingency
If SSD does not shift:
Redress shifting tool and re-attempt.
Equalize pressure across SSD.
If all attempts fail:
Option A: Proceed to Coil Tubing kill (CT RIH to guide shoe, displace with DME emulsion fluid, break circulation every 400m).
Option B: Proceed to bullhead kill with Client approval.
2.4 Reverse Circulation Kill
Line up from annulus to choke manifold.
Pump DME emulsion kill fluid down annulus through SSD.
Monitor all pressures continuously.
Confirm well dead: shut in and monitor 30 minutes.
Close TRSV via control line if applicable.
2.5 Bullhead Kill (Alternate)
Bullhead ±125 bbl DME emulsion fluid into tubing.
Monitor tubing and annulus pressure.
Confirm well dead.
Phase 3: Decompletion
Estimated Duration: 60 hours (2.5 days)
3.1 Prepare for Pulling
Install 4" TWCV in tubing hanger.
Pressure test TWCV: 4500 psi, 15 min.
N/D X-mas tree.
Check tubing hanger neck threads for damage.
Check all tie-down screws operate properly.
3.2 Nipple Up BOP and Test
N/U BOP stack (DSA + Riser + Fix Rams + Double Rams + Annular).
Pressure test all BOP components per test matrix.
3.3 Retrieve TWCV and Connect Landing Joint
Retrieve 4" TWCV.
Make up landing joint / XO to tubing hanger.
Connect pump truck and verify well not flowing.
3.4 Unset Packer and Pull Completion
Open tie-down screws.
Pull up to unset packer per OEM procedure.
POOH completion string while:
laying down each component,
monitoring fluid levels,
retrieving control line and gauge cable on empty reels,
inspecting pulled components.
CRITICAL: All retrieved tools must be sent for inspection as soon as possible (see Section 11).
3.5 Decompletion Contingency
If packer does not unset:
Run electrical back-off tool.
Back off above packer.
Pull free tubing.
Mill out packer.
If packer is permanent type:
Before milling, set a cement plug below packer depth to prevent debris from falling into the well and damaging the ESP pump later. The well must be clean before running ESP.
Phase 4: Corrosion Logging
Estimated Duration: 24 hours (1 day)
4.1 Corrosion Log Run
After completion string is fully retrieved and hole is open:
Rig up corrosion logging equipment.
Run corrosion log inside 9-5/8" casing and 7" liner as required.
Record casing wall thickness, pitting, corrosion anomalies.
POOH and rig down logging equipment.
Submit log results for interpretation.
Decision Point: Based on corrosion log results, Client and Contractor will decide:
Whether casing integrity is acceptable for ESP completion.
Whether remedial cementing or casing repair is needed.
Phase 5: Tubing Head Spool Change
Estimated Duration: 48 hours (2 days)
5.1 Scrape for RTTS and Packer Area
Run 9-5/8" scraper to ±150m (RTTS + new packer depth area, approximately 100-150m below RT).
Scrape by reciprocating.
POOH.
This scraper run must be done before running ESP to ensure clean casing for packer setting.
5.2 Set Cement Inside 7" Liner (For RTTS Integrity / Contingency Dry Test)
This step is required if:
A dry test of the 7" liner lap is required as contingency, OR
RTTS integrity requires cement support.
RIH cementing string.
Set cement plug inside 7" liner at required depth.
POOH cementing string.
WOC (Wait on Cement).
Pressure test cement plug (dry test).
If dry test from 7" liner lap is required:
Set RTTS above 7" liner lap.
Pressure test from above RTTS against cement inside liner.
This confirms 7" liner lap integrity.
5.3 Set RTTS
RIH RTTS packer assembly.
Set RTTS at ±30-40m.
Back off string. POOH.
Perform RTTS integrity test: 800-1000 psi, 10 min.
5.4 N/D BOP
N/D BOP stack completely.
5.5 N/D Old THS
De-energize P-seals.
Open THS studs.
Lift and lay down old THS.
5.6 Prepare Casing Neck
Inspect 9-5/8" casing neck (inner/outer seal surfaces, length, profile).
If required: cut, bevel, dress casing neck.
Requires permit, cutting tools, welding support, Client approval.
5.7 Install New ESP THS
Install new ESP-compatible THS.
Use new ring gasket.
Tighten studs.
Inject P-seal packing compound.
Pressure test all P-seal zones: 4000 psi, 15 min.
Pressure test body and gate valves: 4500 psi, 15 min.
5.8 Reinstall BOP and Test
N/U BOP and test per test matrix.
5.9 Retrieve RTTS
RIH and screw into RTTS assembly.
Unset RTTS.
POOH.
Phase 6: Hole Cleaning, Scraping, Drift Verification
Estimated Duration: 124 hours (5.2 days)
6.1 TD Check Run
P/U cleanout BHA:
3-1/4" flat bottom junk mill + 3-1/8" bit sub (with float valve) + 3-1/8" DC (4 jts) + 2-7/8" DP (HT PAC, jt by jt).
RIH to TD (target depth).
Monitor drag continuously. If abnormal, stop and investigate.
Fill up string every 10 stands.
Wash, drift, measure all DP before P/U.
Tag bottom and record depth.
POOH. Inspect mill.
6.2 Tandem Scraper Run
P/U tandem scraper BHA:
6-1/8" junk mill + 7" scraper + 4-3/4" bit sub + 4-3/4" DC + jar + HWDP.
M/U 9-5/8" scraper on string at appropriate depth.
Scrape 9-5/8" casing interval (±120m below RT) – 5 reciprocations per stand.
Pass 7" lap carefully.
Scrape 7" liner – 3 reciprocations per stand.
Continue to ±2500m (ESP packer area).
Break circulation every 100-200m.
POOH. Inspect all scrapers and mills.

7.7 Check Valve and Drain Valve Tests
M/U check valve assembly with XOs.
Test surface lines: 5000 psi.
Test check valve: 2500 psi, 15 min.
M/U 2 joints tubing.
M/U drain valve assembly with XOs.
Test against check valve: 2500 psi, 15 min.
If leak: torque-up, re-test, replace with backup if needed.
7.8 SSD Installation and Test
M/U SSD assembly (closed, with plug and prong).
Test against plug: 2500 psi, 10 min.
Run slickline gauge ring through SSD.
7.9 Intermediate Pressure Tests
At ±1035m: test string against plug: 2000-4500 psi, 15 min.
At packer depth: test string against plug: 2000-4500 psi, 15 min.
Release pressure gradually.
7.10 Packer Installation
M/U packer assembly (with AGV, penetrators).
Connect AGV CL. Test: 5000 psi, 15 min.
Open AGV. Maintain 2500 psi while running.
Install cable penetrators through packer.
Splice cable at packer penetrators.
Test IR after each splice.
Shallow test packer connection: 300 psi, 15 min (below shear pin force).
7.11 TRSV Installation
M/U TRSV assembly with flow couplings and XOs.
Connect TRSV CL. Test: 500/5000 psi.
Maintain 4000 psi to keep flapper open.
Run SL gauge cutter to verify TRSV ID.

9. ESP CABLE SPLICE PROCEDURE
Covered in detail in Phase 8.
Key Summary:
Do not splice in rain, humidity, or dusty conditions.
Use enclosed splice shelter.
Follow vendor procedure exactly.
Test before and after every step.
Separate IR (MΩ) from conductor resistance (Ohm) in records.
Verify penetrator compatibility before cutting cable.
Maintain minimum bend radius.
Have backup splice kit and penetrator.
10. CORROSION LOGGING
10.1 Scope
After removing the completion string and before THS change, run a corrosion log inside the 9-5/8" casing and 7" liner.
10.2 Purpose
Evaluate casing wall integrity.
Identify corrosion pitting, wall thinning.
Confirm suitability for new ESP completion.
Provide baseline data for future comparison.
10.3 Procedure
Rig up logging equipment.
Calibrate tool.
RIH to target depth.
Log while POOH at controlled speed.
Rig down.
Deliver raw and interpreted data.
10.4 Decision Point
Based on results:
If casing integrity acceptable → proceed to THS change.
If remedial action needed → discuss with Client (cement squeeze, casing patch, etc.).
11. INSPECTION AND REDRESSING PROGRAM
11.1 Scope
All retrieved completion tools and tubing must be inspected as soon as possible after POOH. The goal is to determine:
Which items can be redressed, tested, and reused.
Which items need cut & re-thread.
Which items need to be replaced with new.
New items always have higher reliability. For first-time ESP execution, purchasing new SSD, TRSV, and XOs is recommended to increase confidence.
11.2 Inspection Sequence
11.3 Cut & Re-Thread Coordination
Pre-identify a qualified threading workshop before mobilization.
Confirm workshop can handle: TPG2, HSM3, TPCQ-EX, N.Vam threads.
Confirm turnaround time.
Arrange transport between wellsite and workshop.
11.4 Pup Joint Fabrication
All completion tools (SSD, TRSV, check valve, drain valve, flow couplings) require pup joints to be made-up before running.
Pup joints must be:
Correct thread type.
New or re-threaded and inspected.
Drifted.
Pressure tested if applicable.
11.5 CCCP Fabrication
Cross Coupling Cable Protectors must be fabricated if not supplied by ESP vendor.
CCCP must fit:
4-1/2" tubing coupling OD.
3-1/2" tubing coupling OD.
Coordinate with fabrication workshop.
Quantity: ±130 for 4-1/2" + ±110 for 3-1/2" + spare.

14. CONTINGENCY PLANS
14.1 SSD Not Shifting
Redress tool and re-attempt.
Equalize pressure.
If fail → CT kill or bullhead with DME emulsion.
14.2 Packer Not Retrieving
Max approved over-pull.
Rotation if OEM allows.
E-backoff, pull free tubing.
Mill out packer.
If packer is permanent: Set cement plug below packer before milling to prevent debris from falling into well and damaging ESP pump.
14.3 Cable IR Drop
Stop immediately.
Re-test.
If sustained drop → consult ESP vendor.
Do not continue with unacceptable IR.
14.4 Check Valve / Drain Valve Leak
Re-torque.
Re-test.
Replace with backup.
14.5 THS / THA Mismatch
Measure and compare with drawings.
If casing neck cutting needed → permit and execute.
If penetrator rod does not fit → send to WH manufacturer for machining.
14.6 7" Liner Lap Dry Test (Contingency)
If 7" liner lap integrity must be confirmed:
Set cement inside 7" liner below lap.
WOC.
Pressure test cement.
Set RTTS above 7" liner lap.
Test from above RTTS against cement.
This confirms liner lap seal.
14.7 Weather Delay
No splice in rain/humidity.
Heat/insulate test lines in cold weather.
Winterize rig systems.
14.8 Tong / Torque Gauge Failure
Switch to backup.
If backup fails → stop and request replacement.
14.9 Liner Lap Cannot Be Passed
Verify depth reference.
Apply 2-5 kips only.
Rotate 1/4 turn.
If no success → POOH and investigate.
14.10 Thread Damage on Retrieved Tubing
Separate damaged joints.
Send to cut & re-thread workshop.
If body OK → re-thread.
If body damaged → scrap.
Use new tubing if time-critical.
