Objectives: RUN TGB AND DRILLIN STRING

    1- PREPAR TGB AS PER SPECIALIST GUIDE (GUS)
    2- HOLD SFETY MEETING.
    3- RUN TGB AS PER SPECIALIST GUID LINE IN ATTACHMENT.
    4- AFTER SET TGB AND PULL BACK SETTING TOOLS PREPAIR TO MACK UP BHA.
    5- PICK UP AND MACK UP BHA AS FOLLOWS.
    6- 26” ROCK BIT DRESSED BY 3x20 NOZZLE + 36” HOLE OPENER + BIT SUB WITH
     FLOAT VALVE IN + 9-1/2” PNMDC + POWER PULSE + 9-1/2” NMDC + 6 JOINT 9-1/2”
     DC+ CROSSOVER+6 JOINT 8” DC+15 JOINT 5-1/2” HWDP +5-1/2” DP TO SURFACE.
    7- RIH TO TGB AND START DRILLING TO 132 MT BELOW SEABED BY SEA WATER.
    8- PUMP 50 BBL HI-VIS PILL EACH 15 MT DRILLING.
    9- AFTER FINISH DRILLING CIRCULATE BY SEA WATER SWEEP THE WELL BY PUMP
      100 BBL SPOT KILL MUD AS PER CAP. OF HOLE.
   10- POOH TO SURFACE.
   11- RUN PGB AS PER SPECIALIST GUIDE LINE.
   12- NEXT PLAN ON TIME PRESENT. .
