            COMPLETION STRING PROGRAM

                 «KANGAN-25 / RIG FA84»


  Important Note:
    If the well was under complete loss, while running completion string from surface to the
   packer setting depth, fill up annulus by fresh water at a safe rate as experienced in the
   previous killing and cleaning operations. Fill up tubing but all the time leave about 300m-
   400m of the tubing empty to avoid premature set of packer.

   Prior to set packer start filling up with corrosion inhibited completion fluid. Fill up the
   annulus after setting packer till got level at surface.


A-Completion Surface Tests:

     1.  Drift and measure OD, ID and length of all completion equipment and accessories.

     2. Wash all joints with fresh water on Rack & when pulling up to run in hole.

     3.  Set dummy in 3SV L/nipple, connect Control line and test against dummy to 5000 psi.

     4.  Set plug in Top no-go L/nipple and test to 4500 psi, leave the plug set. (Check it to be
        retrievable).

     5.  Adjust PBR in full closed position and set shear pins.

     6.  Set dummy injection valve in SPM and test to 4500 psi.

B-Completion Running Procedure:

          •  Remove wear bushing.
          •  Rig up completion running tools.

     1. RIH as per attached tally (with plug in Top no-go L/nipple) up to 3SV L/nipple.

    Note: Fill up 200m on top of no-go plug with Hi-Vis corrosion inhibited polymer pill
    (≥120sec) and the rest of string by corrosion inhibited gas oil.


     2.  Continue RIH as per tally plus one 10 feet pup joint (Length of pup joint is fixed as
        half of the length of PBR stroke and its position is blow the first joint under tubing
       hanger), Pick up tubing hanger.

    Important Note: Do not connect control line in this process.

     3. P/U 7” Landing joint, connect to tubing hanger.

     4. R/U Pump unit.

     5.  Flush and clean tubing head spool with water (or by air).

     6. Land tubing hanger and tighten all the tie down screws.

    Note: A sudden strong upward shock might be exerted to the string while setting packer,
    so special care should be taken to fully tighten the entire tie down screws.

     7.  Set packer as per procedure and pressurize tubing to 4500 psi step by step (500 psi on
       each step @ 3 min.) and monitor tubing annulus at same time (open tubing head spool
        side outlets).

   Note: While pressurizing inside tubing to set packer, if the well static, some back flow will
   be observed through tubing head spool side outlet valves, it should be stopped after a while.

     8.  Release pressure, loosen tie down screws, over pull the string with proper tension (as
       anticipated by the strength of the shear pins).

    Note: The over pull is calculated by the number and the metallurgy of the shear pins. Here
    10 No of steel shear pin (10000 lbs) are used. (Hydraulic release value: 3600 psi, and shear
    release value: 100000 lbs according to weatherford PBR catalogue).

     9. Loosen tie down screws. Pull out string and shear off PBR shear pins. Continue pull
       out string up to 3SV landing nipple (Remove pup joint from string), Connect control
        line to 3SV L/nipple and test to 4500 psi against dummy. Band control line straps to
        tighten same against tubing.

10. RIH, Pick up tubing hanger. Connect Control line to same and test to 4500 psi.

11. Land tubing hanger.

12. Tighten tie down screws.

13. Close BOP's rams on tubing and pressure test tie down screws in open position (with
    1000psi).

14. Test inside tubing to 4500psi (15 min), close top rams and test Hanger & tie down
   screws (in closed position) to 2000 psi.

15. Test annulus to 2000 psi (15 min), and back off Landing Joint.

16. Set two way BPV inside tubing hanger and pressure test to 4500 psi.

17. N/D BOP's.

18. Check hanger for any damages. Pressure test control line to 4500 psi against 3SV
   dummy.

19. Nipple up wellhead as per program. Pressure test same.

20. Remove two way BPV from tubing hanger.

21. Connect flow line and chock manifold to the X-mas Tree, R/U wire line equipment and
    lubricator. Test wellhead, chock manifold and flow line and wire line equipment to
   4500psi.

22. Remove prong and plug from Top no go nipple.

23. Flow the well through variable choke sizes to clean up the well.

24. Clean the well, record the flowing pressures on different choke sizes and burning line
   pressure at the same time.

25. Close the well.

26. Remove dummy.

27. Flush control line with hydraulic oil.

28. Install 3SV and test control line to 4500psi.


29. Release above SSSV pressure to zero.

30. Monitor wellhead pressure for any 3SV leakage.
