Objectives: Run 18 5/8” Casing

Planned Operations:

    1.  Clear rig floor. Transfer 18 5/8” swage to rig floor.
    2.  Install long bails and casing side door elevator. Prepare hand slips and 20” Bushing.
    3. R/U casing handling tools, and prepares all welding equipment on rig floor.
    4. Hold pre job safety meeting with all personnel involved in operation.
    5.  Pick up float shoe joint and set it on rotary table. P/u and check for full drainage. Run back and check float

            (if the water level in the riser can be observed).

    6. P/U and M/U joint # 40 & differential float collar joint. Use baker lock on connection (Optimum torque will

      be obtain by using tri-angle mark and should be around 15500 ft-lbs).

    7. Run 18 5/8” casing as per tally. Install centralizer as per tally around coupling.
    8. Run to 175m.
    9. Change side door elevator to spider elevator.
   10. RIH w/ 18 5/8” casing in open hole to 968m. During RIH if got weight, engage Fill up tools, start to pump

      and try to wash down. Working with laflour should be done according to ITS advice.

   11. Wash down last joint during RIH.
   12. After running joints no#1, Spot 100 Bbls PHG Around shoe (Do not pump water out of shoe), Set the

       spider slips. Remove coupling. Install 18 5/8” C.H.H as per Aker solution engineer instruction. Make sure

        that the short VR plugs installed on the C.H.H. Orient CHH side outlets. (Orient as same as well # 2).

   13. P/U and M/U R.T joint and install R.T.
   14. Cont RIH as per tally with wash down & land CHH in 26” CP.
   15. After finish RIH, count number of remaining casings.
   16. Circulate 1.2 csg volumes with SW .record rate and press.
   17. Line up and arrange lines to cement unit. We will displace cement with mud pump.
   18. Cement program will be issued later.
