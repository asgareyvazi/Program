1. Introduction


     1.1    Program Introduction

              This program covers workover of well No.6, of Sarkhoon gas field, I.R.Iran. The well is gas
              producer from Guri Bazdeh formation right now.

            Problem
            The tubing annulus (9-5/8”x7”) pressure was checked 1400 psi. Temperature log was run that
            showed leakage from Packer area (±2400m).

           Main Objective
           The main objective of this program is to fix the problem and to resume gas production
            from Guri Bazdeh formation.

             Note: This program has been written with respect to the available information of workover
               request no. ٦٨ / ٨٠٢ / چ ت ب ,dated: ٦٨٣١ / ١١ / ٩٢ South oil & gas production Co.


           The main head lines of this program are as follow:
                1.  Checking wellhead for any damage or leakage.
                2.  Connecting killing, flowing and return lines
                3.  Record well head pressures, investigate for pressure relations
                4.  Kill and secure well
                5. N/D well head and N/U BOP's
                6.  Pull out completion string
                7.  Scrap and clean inside 9-5/8" casing to 7" Liner Lap
                8.  Scrap and clean inside 7" Liner to Packer Depth
                9.  Pressure Test HB Packer and inside 9-5/8" casing using 7" RTTS
              10. Mill out and recover packer and its tail
              11. Run completion string
              12. N/D BOP's and N/U well head
              13. Flow the well
              14. Securing well and releasing rig


              Attentions:

                •  The detailed program is illustrated here after in this document under the
                 head of "Workover Program".

2. Workover Program

     2.1 Sequence of Workover Operation

                1. Move from SA-3 to the well site of SA-6, R/U and make it ready for operation, Record
                   rotary table and tubing head spool elevations from sea level.

                2. The well head spools, valves & P-Seals and x-mas tree must be checked and
                  serviced by well head specialist. Shall it necessary, well head components should be
                  repaired after being L/D on the well site or at AHWAZ workshop.

                3.  Connect killing & flowing lines to the x-mas tree side outlets and connect return line
                    to 2-1/16" -5000 side valves of tubing head spool. Test all to 4500 psi pressure.

                4. Record the wellhead pressures; those of tubing, 7" x 9-5/8" annulus, 9-5/8" x 13-3/8"
                annulus and 13-3/8" x 18-5/8" annulus. Release / Bleed off pressures, monitor their
                   build up and investigate for the probable relations.

             Note: Take enough care to consider the collapse and burst pressures of pipes
             while relation investigation.

                5.  Rig up wireline equipment; test same and lubricators to max 4500psi pressure. Set
                "XN-2.750" no-go plug @ ±2414.39m. Test same and inside tubing to max 4500psi.
                 released pressure in annulus (or tubing), investigate any pressure build up and
                 probable leakage from packer. Remove "XN-2.750" no-go plug.

                6.  Bullhead the well by pumping fresh water which its full column imposes 388 psi over
                 pressure to the reservoir @ top perforations (2446m). Shall could not able to
                 bullhead continued from step-7.

             Note: Monitor the pressures of annuluses all the time.

                7.  Rig up wireline equipment; test same and lubricators to max 4500psi pressure. Set
                "XN-2.750" no-go plug @ ±2414.39m. Test same and inside tubing to max 4500psi.
             Open SSD. Displace the well by fresh water, balance mud weight, observe well. (its
                          full column has 243.6 psi over pressure against the reservoir pressure @ SSD depth
                 (±2389.68m).

             Important Note: before opening SSD, release the annulus pressure for 500 psi. Monitor
            and record any pressure build up in the tubing annulus. In case of any pressure build up
            complementary program will be issued in due time.

                8.  Close SSD, pressure test same to 4500 psi. while circulate cross wellhead, Monitor
                  7" x 9-5/8" annulus for any flow (in case of observe any flow, Kill the well using
                 proper mud weight), Install Back Pressure Valve inside tubing hanger (Type "SA2")
               and pressure test same to 4500psi. Shall it impossible to set BPV, install dummy and
                 plug into 3SV landing nipple (Type "RQL") and pressure test same to 4500 psi.
