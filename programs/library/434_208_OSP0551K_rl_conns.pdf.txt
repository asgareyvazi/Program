EQUIPMENT


  RAPID LOCK CONNECTORS - TYPE RL-4, RL-4RB

TECHNICAL DESCRIPTION


   RL-4 Rapid Lock connectors greatly reduce rig time to run conductor and casing strings
   by providing quick stabbing and make-up. Rapid Lock connectors are available in sizes
   and styles for drilling and driving in a variety of applications.

    All Rapid Lock connectors feature self-locking 4-start threads, which provide make-up
   with only ¼ to ½ turn of the suspended joint.





                                                      RL-4



   The RL-4 connector is available in 22”, 28”, 30" and 42" sizes while the RL-4RB
   (Reduced Bore) is available in 30", 36", and 42" sizes. Both RL-4 and RL-4RB
   connectors are manufactured with an integral secondary locking (anti-rotation) device.

This anti-rotation lock is set by a portable, hand held tool. The tool is positioned against
the box, and indexed in a milled slot on the pin. Activating the tool shears one end of a
box strip and depresses it into the pin slot, preventing connector backout.

Each of these anti-rotation strips provides approximately 400 ft-lbs resistive torque per
inch of nominal pipe diameter. The desired breakout torque resistance (number of strips
to shear) is up to the operator’s discretion.

Accessory equipment used in driven RL-4 conductor strings include a threadless Drive
Sub, a Remote Release Extension Tool, and a torque tool release able RL-4 for direct
torque release at the mudline.

The non-threaded Drive Sub allows driving directly on the pin of the RL-4 connector.
The drive sub attaches to the hammer and greatly speeds the driving operation. The
drive sub has an extension of pipe above the driving surface that accommodates most
hammers and leads. A stabbing cone below the driving surface aids stabbing and
positions the sub properly on the connector.

A remote Release Extension Tool can be used to apply torque above the rotary for
special application connector release at the mudline when the conductor has been cut
below the rotary (at the cellar deck level).

Contact Vetco Gray’s Engineering Department for more information when driving RL-4
connectors and using these accessory tools.

ROUTINE OPERATION


                   PRE-OPERATIONAL CHECKS

    1.  Remove protectors. Clean pin and box members thoroughly.

    2.   Inspect the threads and metal shoulder surfaces for dings or other shipping
       damage. Any joints with damaged connectors should be clearly marked with red
         paint and stored separately.

    3.   Inspect and replace any damaged o-ring seals.

    4.   Reinstall protectors before moving RL-4 joints from pipe racks. Always use
        protectors when handling casing and conductor joints. Connector thread
      damage could adversely affect make-up and breakout and connector
       performance. Never apply lifting hooks directly to connectors.

    5.   Immediately before running, lubricate both pin and box with Jet Lube AP-5 grease.
       Heavyweight oil, or equivalent may be substituted. Do not use thread dope or
        lubricants containing metal or metallic compounds. These compounds will
        not allow the threaded connector to make-up fully, can prevent the connection
        from sealing and can cause galvanic corrosion.

    6.   Refer to manufacturer’s instructions for operation of the locking tool used.
        Manually operated tools are available in addition to the power operated tools.


                            CAUTION:


 The cartridges are color coded according to power. Do not use any color except
 yellow in the locking tool. Higher powered purple cartridges can damage the tool.


                     RUNNING PROCEDURE

General

   The reduced bore 30", 36" and 42" RL-4 connectors must be run in the box up mode
   unless pad eyes or a similar method of support is used, because there is no elevator
   landing shoulder on the connector pin. All other RL-4 connectors can be run pin up or
   box up. Run connectors pin up when driving.

   Relatively low torque is required to make-up the connector until  it shoulders out,
    anti-rotation strip and slot align, and it exhibits its full structural strength. Torque can
   vary depending on connector cleanliness. However, it is important to control and record
   make-up torque and coordinate this with the number of anti-rotation strips to be sheared
    in anticipation of future releasing/retrieving operations. Recommended torque is listed
   on page 5.

   Neglecting the contribution of the anti-rotation strips, connectors break out within 10%
    of make-up torque.

   Connectors that will be driven should be made up with at least 30,000 ft-lbs, using
   suitable make-up and backup tongs, and the torque recorded. At least one anti-rotation
    strip should be set; two are recommended. (Additional tabs can be set to increase
   breakout torque resistance).

Remote Release

   The DMR, the Left Hand RL-4, and the Torque Tool Releaseable (TTR) version of the
   RL-4 connector are available for remote release applications. Contact an Vetco Gray
   sales representative for assistance in selecting the appropriate connector to meet the
    specific requirements of the drilling program.

     If a particular connector will be released by turning a string of right-hand connectors to
   the left, the breakout torque of that connector must be lower than the rest of the string.
   This can be achieved by a combination of a lower make-up torque and shearing fewer
    anti-rotation strips. Make-up torque should still be within the recommended torque
   range. This method is not recommended because side loading (caused by
   currents or rig off location) can significantly increase the breakout torque of a
   connector at the mudline. Uncontrolled high left-hand torque to disconnect at
   the mudline could cause disconnect of an unplanned connector.

   Use backup tongs when making up or breaking out connectors in a string where this
   might release a connector at another location.

Procedure

    1.   Pick up a joint with casing elevators, slings, or handling tool, stabilize over
        previous joint and remove the protector. Carefully stab into preceding joint.

    2.   For best make-up performance, the oval anti-rotation strip slot should be aligned
        approximately one inch to the right of the pin slot when running a right-hand
        connector in the pin up mode.

        Left-hand connectors in the pin up mode or right-hand connectors run box up will
       make-up in ¼ turn when the box strip is one inch to the left of the pin slot. If the
        connector is not aligned, it can take up to ½ turn for make-up.

    3.   Slack off all the weight on the hook before rotating the joint slowly with casing
        tongs. Do not apply tongs directly to box. Apply torque to pipe above the box.

    4.   Rotate joint to shoulder the connector, then tighten to recommended torque in
       accordance with table. Make-up torque can be increased for higher preload, but do
        not exceed the maximum torque listed.

5.  When engaging the anti-rotation tabs, place the cocked locking tool (Hilti) into
     position with the flat mandrel on the cutting head being inserted into the portion of
     the milled slot on the pin that extends above the face of the box. The flat surface of
     the mandrel on the cutting head should rest on the face of the box. Move the tool
     against the side of the slot to where the cutting blade is positioned such that it will
     shear the tab in the direction that prevents back out of the connector.

    Press the locking tool firmly and squarely against the connector, depress the
     safety latch and pull the actuator. One end of the anti-rotation strip should have
    sheared off and be firmly seated in the pin slot.  If it is not, re-cock the locking tool
    and perform the locking procedure again to fully seat the sheared end of the strip.
    Re-cock the tool and set additional anti-rotation tabs as required.

    The correct lock can always be double checked by imagining the pin being
    unscrewed from the box and checking that the tab is preventing this movement by
     acting on the pin slot side.

6.  When connectors are made up to the recommended torque, the milled windows in
     the box should overlap the milled slots on the pin as shown on the drawing below.
    The dimensions shown in this drawing are nominal. Variances can occur due to
     manufacturing tolerances, coating, etc. The tab can be sheared on the plus side
    as long as the window in the box overlaps the milled slot in the pin. The tab can be
    sheared on the minus side where the 1.69 measurement shown below is as short
    as 1.25”.    It is possible to shear tabs with lengths less than 1.25”; however,
    bending the tab into the pin slot will become increasingly more difficult.

        If the anti-rotation features on the pin and box do not align properly place a mark
     across the pin and box indicating made up orientation. Then break the connection
     apart and check for cause of incomplete make up such as debris between the pin
    nose and box internal shoulder or thread damage. Record pin serial number while
     pin and box are apart. If connectors are free of debris or damage make up pin and
    box such that orientation marks are 90 degrees apart from original make up
     position. If anti-rotation slots still do align such that tabs can be sheared record the
    box serial number and contact the Vetco Gray Service Department for further
     options.

Hammer Activated Shear Tool

      A hammer activated shear tool can be used instead of the Hilti tool. This tool
        performs the same task as the Hilti tool but a sledge hammer is used to hit the
        shear tool and shear the anti-rotation tabs. The part numbers for this tool can
       be one of the following:

            H50115, A30175-3, A30175-4, R30015-1, R30060-1, R30315-1

                        RECOVERING

  The procedure for recovering a conductor string above the mudline depends
  on the type of connection used at the retrieval point. This procedure assumes
   the recommended use of a left-hand thread driveable remote release
   connector in the right-hand string, made up to a documented torque.

    1.   Support the surface string weight on the hook.

    2.   Either jump a diver to pry out the locking strip(s) on the connector at the mudline
        with a pry bar or, using casing tongs, apply sufficient torque to the right to
       overcome the strip(s). Continue rotating to the right until the joint is disconnected.

    3.   Pick up on the string as soon as the threads disengage, until the following joint
       can be suspended at the rotary.

    4.   Using a pry bar, pry the locking strip on the surface connection outward until
         clear of the pin slot. Repeat for other anti-rotation strips.

    5.   Using casing tongs, break the connection, install pin protector and move the
        recovered joint to the pipe rack. Repeat for remaining joints.

                POST OPERATIONAL MAINTENANCE

   Post operational maintenance is necessary only if the tool joints are recovered and
    will be reused.

    1.  Wash the pin and box members with fresh water.

    2.   Clean the threads and shoulder area of both pin and box, and inspect for
       damage. Any joints with damaged connectors should be set aside and clearly
       marked with red paint.

    3.   Inspect and replace any damaged o-ring seals.

    4.   Lubricate the threads and install thread protectors.
