                          W030 (SI-008)

                                  Procedure No1 SI-08

                                 5-7/8" hole Procedure

1) Run coring BHA to 4680m (core point), take Core F/4680 to 4820m(140m) as per C.P.

2) L/D coring BHA.

3)  P/U Last 5 7/8" PDC Bit, RIH  to 4680m.

4) Wash & Ream Cored Interval to 4820m.CBU.

5)  Cont. Drilling 5-7/8" hole section f/4820 to 4900m (Well TD).

6) CBU. Condition hole Prior Full Set log.

7) POOH To Surf & L/D Bit & BHA.

8) R/U Logging Equipment. Run Full Set log of Bangestan Fm with TLC Method .

9)  P/U 5 7/8" PDC Bit and BHA, Condition hole Prior Image Logging         .

10) Run Image Log of Bangestan Fm.

   Note: if Image Log was not Performed, CDR/GR log should be Performed Instead) With TLC

   Method.

11) P/U 5 7/8" PDC Bit and BHA, Condition hole Prior 5" Perforated Liner. Spot 100 bbls Hi-Vis

     Pill @ bottom.

12) Run 5" perforated Liner & Hang same .

13) POOH to Surf., L/D setting tools.

14) RIH W/ 4-1/8" Bit (J.Mill) While P/U 2-7/8" DPs.

15) Perform check trip to 5" P.liner Shoe.

16) Circ BTM's Up. POOH & L/D Bit .

17) P/U 9-5/8" Scraper & Scrap packer setting depth.

18) Circulate bottom's up. Clean the well.

19) Displace well with completion fluid as per procedure.

20) POOH to Surface.

21) Run 7'' * 4 1/2" -5K Completion String.

22) N/D 13 5/8"-5K BOP Stack.

23) N/UP X-mas Tree & Pressure Test All.

24) Perform Injectivity, Well Stimulation and Well Flowing as Program.

25) Close All Wellhead Valve Except BTM Valve Secure the well

    Note: Perform BOP test as per NIOC policy
