
NOTE* Maximum casing load on hanger receptacle 560,000lbs.
Maximum set down weight above casing hanger running tool 80,000lbs.
1/Pick up 16´´ Casing hanger running tool and make up to a stand of drill pipe and rack back in derrick with the Cement plug equalizing sub made up below the running tool.
2/Run 16´´ casing in hole as per procedure.
3/Pick up 16´´ casing hanger and make up to casing string.
4/Pick up running tool from derrick and install cement plugs and grease plugs.
5/Install MS pack off seal to casing hanger. 3 to 6 shear pins can be used. 3 shear pins = 15,000lbs of weight to shear. 6 shear pins = 30 to 40,000lbs depending on the make of the shear pin.
6/Install the lead impression blocks if required to the running tool.
7/Insert the running tool to the casing hanger and put in 3 left hand rotations. Pick up slowly to ensure running tool has locked.
8/Run assembly thru table and ensuring no rotation of string
9/When above stack ensure the hook is unlocked and open choke and kill lines and also stand pipe                     manifold to atmosphere and continue to lower through wellhead
10/Lowering rate should not exceed 3m per minute during last 3m. When landed verify correct measurement and set down 30000lbs. Index and mark a line at table on drill pipe (mark 1 and 2)
11/Pick back up 20,000lbs so only 10,000lbs set down.
12/Rig up cement hose.
13/Circulate and cement.
14/Check weight is still 10,000lbs set down on landing string and rotate pipe RH (3 ½ turns total) keeping a count of turns. Do not exceed 3 ½ turns in the string. If lost count, put turns back into string and start again.
15/Slack off a further 20,000lbs and string should move to mark 2 and Index. 3´´ Drop
16/Close BOP and pressure test to 3000psi. After good test bleed off and open rams.
17/Apply over pull to recover running tool from Hanger of around 10,000lbs.
Pull out of hole.
