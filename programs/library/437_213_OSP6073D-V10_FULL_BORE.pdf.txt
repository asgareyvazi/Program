  FULL BORE CASING HANGER RUNNING TOOL, MS SERIES - 2 TRIP SYSTEM

TECHNICAL DESCRIPTION


   The MS Full Bore casing hanger running tool is designed to allow the use of casing as
   the running string when running exceptionally heavy casing strings or when  it is
   desirable to perform full bore cementing jobs. If required, drillpipe adapters can be
   supplied for this tool. Drillpipe adapters are fitted with a pin connection down to
   accommodate a cementing plug launcher. The tool is designed to run the seal after the
   casing hanger has been run and cemented, therefore pressure testing is not required.

   The lower body has a special left hand thread collet ring on the OD which makes up to a
   mating profile on the ID of the casing hanger. The o-ring seal prevents circulation
   between the casing bore and annulus. The upper body has a 2 pitch right hand modified
   square thread on both ends with a smooth OD in between to carry the centralizer
   sleeve. The lower thread profile makes up to the lower body, while the upper thread
    profile is used for the various casing or drillpipe adapters. O-rings provide seals
   between the pieces when made up.

ROUTINE OPERATIONS


                   PRE-OPERATIONAL CHECKS

General Notes

     It is best to assemble the casing hanger and running tool prior to running casing.
   Lubricants containing metallic particles such as drillpipe thread dope must not
   be used on the casing hanger, annulus seal or running tool threads.

   Review OSP 6069 for the Drillpipe Running tool (DPRT) or OSP 6127 for the Pressure
   Assist Drillpipe Running Tool (PADPRT) for running the seal.




CAUTION:

The design of this tool does not allow for reentry into a casing hanger subsea or
remote visibility as the collet ring can be dislodged from the tool.




Running Tool

   The design of the tool does not allow for the MS seal to be run with the casing
   hanger.

    1.   Clean and inspect the special left hand thread and collet ring for damage or burrs,
        re-dress as required. Inspect the o-ring and replace if damaged. Lightly grease the
         o-ring seal. Inspect anti-rotation keys for damage and replace if necessary.

    2.   Verify the casing adapter is compatible with the selected running string. If the
        adapter is substituted, inspect (replace  if required) the o-rings, lubricate the
         straight threads, and torque to approximately 10,000 ft-lbs (13 560 Nm). Make up a
       pup joint into the adapter after the adapter is made up to the running tool. This
        torque should be approximately 1,000 ft-lbs(1 356 Nm) more than is used to make
        the casing below the casing hanger.

                    RUNNING PROCEDURE

   1.   Verify all wear bushings and/or nominal seat protectors have been retrieved from
       the wellbore, and  if not, retrieve them using the established procedures.  If
       required, retrieve the ball/flex joint wear bushing. Record all space out and landing
      dimensions when retrieving the nominal seat protector or wellhead wear bushing.
       Refer to Vetco Gray procedure on Dwg. No. 50262-1.

   2.  Commence running casing.


                           CAUTION:


Vetco Gray strongly recommends that casing centralizers and scratchers not be
used. Field experience has shown that parts can break off when passing through
the BOP stack and lodge in the wellhead area, preventing the hanger from seating
correctly, also preventing the annulus seal from sealing.


  3.   With the last joint of casing hung off in the rotary, unlock the hook and pick up the
      preassembled casing hanger/running tool assembly.

   4.  Exercise care when making up the casing hanger pup to the last joint of casing.
      The entire casing hanger/running tool/running string assembly should be treated
      as one unit. If the running string is rotated during make up, refer to the chalk marks
      and realign these marks. It is suggested that running string joints are made up
       using approximately 1,000 ft-lbs (1 356 Nm) more torque than is used to make up
       the casing joints below the casing hanger. This extra torque will result in less
      “make up” in the running string when releasing the running tool.

   5.  Torque all connections on the running string to the maximum torque per the
       manufacturers recommendations.

   6.    It is suggested that the choke and kill lines are opened to atmosphere to minimize
       pressure surges when running through the BOP stack with the running tool/casing
      hanger assembly.

   7.  With the hook unlocked and heave compensator adjusted to support all but 5,000
        lbs (2 268 kgs) of the running string weight, lower the casing hanger through the
      marine riser and BOP stack. Note the load on the weight indicator. Continue to
       lower the string and land the casing hanger in the wellhead housing. Verify the
      hanger is landed in the proper position according to the measurements taken
     when the seat protector/wear bushing was retrieved. Close the choke and kill lines
        after the hanger has landed.

   8.   Circulate and cement as required.

                          WARNING:


 DO NOT PICK UP OR ROTATE THE RUNNING STRING UNDER ANY
 CIRCUMSTANCES WHILE CIRCULATING OR CEMENTING. ANYTHING THAT
 COULD PREVENT THE CASING STRING/CASING HANGER TO ITS SEATED
 POSITION WILL AFFECT ALL SUBSEQUENT CASING HANGER POSITIONS IN
 THE WELLHEAD HOUSING.


    9.  Immediately after cementing, open the choke and kill lines on the BOP and flush
          until clean returns are observed. A minimum of twice the riser volume  is
       recommended.

   10.  With cementing completed, while circulating take an overpull of 5,000 lbs
        (2 200 kgs). Place tongs (preferably power tongs) on the running string and rotate
         to the right, while maintaining the 5000 lbs (2 200 kgs) overpull. Rotation of the
        running string backs out and thus releases the running tool collet ring from the
        casing hanger.

   11.  After approximately 2 to 2-1/2 turns at the running tool, the tool is unlatched and
           will be pulled free from the hanger by the motion compensator. It may take more
       than two turns of the casing running string at the floor to release the running
        tool due to make up of couplings in the running string.

   12.  Pull the running tool out of the hole.


Running the MS Seal

    1.  Run the MS Mill And Flush Tool to clean the seal area prior to setting the seal
       assembly. It is recommended that the choke/kill line be used to assist in flushing
        the BOP and Riser during the Mill and Flush operations. A minimum flush of two (2)
        times the riser volume will help verify that all cuttings and/or cement are removed.
        For detailed procedures, follow Operating and Service Procedure 6071.

    2.  The seal assembly must now be run using the DPRT (OSP 6069) or the PADPRT
      (OSP 6127). If required, a jetting sub can be installed below the DPRT/PADPRT to
         flush the seal area just prior to setting the seal. Drillsites having difficulties with
       removing “tailings” from the BOP/Riser should continue to use the
        choke/kill line to flush the BOP/Riser while running the seal assembly. A
       “Gel Pill” pumped into the BOP/Wellhead area will also assist in preventing
        trash and debris from interfering with the proper installation of the seal
       assembly.

               POST OPERATIONAL MAINTENANCE

    1.   Thoroughly wash the running tool with fresh water.

    2.   Inspect the special running thread and collet ring for burrs. Re-dress as required. If
        the collet ring has been damaged, remove lock pins and back off retainer and
       remove the collet ring. Replace with a new collet ring and reinstall retainer and lock
         pins.

    3.   Inspect the anti-rotation keys and o-rings, and replace each if damaged.

    4.   Apply a corrosion inhibitor to all surfaces. Install protectors and place in storage.
