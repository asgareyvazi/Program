Well AZNS-36 Securing procedure:
Record wellhead and Ann. Pressures.(Bleed off pressures if observe pressure in annulus)
Note: Take sample mean while bleeding off and monitor pressure for 24 Hours
Check DHSV Function, Close DHSV, Bleed off pressure, Set two way BPV in Tubing Hanger and Pressure Test Same.
Disconnect all Surface lines from X-mass tree and N/D same.
Install blind flange and gate vale, Pressure Test against TWBPV
Secure the well.
If DHSV failed:
R/U slick line lubricator RIH with slick line.
Set protection sleeve in TRSSSV
R/U Coil tubing
Set plug & prong in NO-GO landing nipple.
Set BPV in Tubing Hanger, Install blind flange and gate valve, Pressure Test against TWBPV then secure the well.
Note: All Press. Test should be perform W/ 80% Equip. working Pressure
Well AZNS-17 Securing procedure:
Record wellhead and Ann. Pressures.(Bleed off pressures if observe pressure in annulus take sample mean while bleeding off ,then wait and monitor pressure for 24 Hours,)
R/U Coiled Tubing, Retrieve WSSV, Set Dummy in DHSV Replace Well Fluid with Diesel
Close DHSV, Bleed off pressure, Set two way BPV in Tubing Hanger.
Disconnect all Surface lines from X-mass tree.
If DHSV failed:
R/U slick line lubricator RIH with slick line.
Retrieve WSSSV and set dummy.
Set plug & prong in NO-GO landing nipple.
Displace above the plug with diesel by coiled tubing.
Set BPV in Tubing Hanger, After Set TWBPV, Pressure Test against TWBPV
Disconnect all Surface lines from X-mass tree.
