                   Procedures for Backing Off the 7 5/8" Casing

(vi)    Make up 5 5/8" OD casing back-off assembly and RIH.

                 Make up the following equipment :

                5 3/4" OD Bullnose                   3 1/2" If Box
                5 5/8" Casing Bottom Anchor Section    3 1/2" If Box x Pin
                5 5/8" OD Lubricated Slack Joint        3 1/2" If Box x Pin
                5 5/8" OD Torque Generator Section     3 1/2" If Box x Pin
                5 5/8” OD Clutch Unit                3 1/2" If Box x Pin
                5 5/8" Casing Top Anchor Section       3 1/2" If Box x Pin
                 Swivel Joint with landing shoulder       3 1/2" If Box x Pin
                5 5/8" OD Slack Joint                 3 1/2" If Box x Pin
                 By-Pass Valve                       3 1/2" If Box x Pin
                   Circulating sub                      3 1/2" If Box x Pin
                  Crossover sub                       3 1/2" If Pin x 4 1/2” IF Box
                 5" OD Drill pipe to surface


(vii)    RIH with back-off assembly to back-off at the first casing collar below the top of the stump.
       Once the back-off assembly has been lowered into the casing continue slacking off until the
         landing shoulder is resting on the top of the stump, the upper slack joint has closed and
        20,000 lbs of weight is resting on the stump.

(viii)    Pick up the string to put the upper slack joint in mid-stroke leaving the weight of the back-off
        assembly (7,500 lbs) resting on the landing shoulder.

      Make Sure Blocks Are Unlocked for Work String to Be Free to Rotate While
       Suspended in the Elevators. This is a precautionary measure as no rotation should be
        seen at surface due to the Swivel Sub in the tool.

(ix)       Initiate the back-off sequence by bringing in the pumps up to 150-200 Gpm. This will close
         the by-pass valve and allow pressure to be exerted on the anchor sections and torque
         generator. As the pressure increases (Max 5000 psi) breakout of the connection should begin,
          this may be noticed by a fall off in pressure as the connection breaks. At the end of one cycle
         (1/2 a turn) the pressure will increase indicating the end of the tool stroke. Hold pressure for
        5 minutes.

                   Procedures for Backing Off the 7 5/8" Casing

(x)      Bleed off the pressure to zero. As this is done the tool will reset itself in preparation for the
         next torque cycle.

(xi)      Restart the pump and increase the pressure again to activate the torque generator. The
         pressure peak on this cycle should be less than on the previous cycle, however pressure up to
        5000 psi regardless, as less force will be required to unscrew the connection after the initial
         breakout.

(xii)    Repeat the cycling procedure until eight cycles have been achieved. At this point four full
         turns should have been applied to the casing connection.

(xiii)   Drop the circulating sub ball and open the circulating sub with 1500 psi. POOH.

(xiv)   Run back in the hole with a standard 7 5/8" spear assembly, engage the casing stump and
        complete the back-off. Recover same.

                7 5/8" Casing spear                   4 1/2" If Box x 3 1/2" If Pin.
                c/w 6.095” Nom grapple
                6 1/2" OD Stop Mandrel c/w 8 1/4" Stop  4 1/2" If Box x Pin
                6 1/2" OD Bumper Sub                4 1/2" If Box x Pin
                6 x 6 1/2" OD Drill Collars             4 1/2" IF Box x Pin
                 5" OD Drill Pipe to surface

(xv)      If remaining casing is pin up, make up 7 5/8" casing alignment tool (Special manufacture)
        onto the first joint of casing and run new casing string.

Note:   Brushing tool may be utilised to clean inside box up if deemed necessary.
      An internal guide assembly will be used if casing is box up and can be stripped in to aid in
         connection alignment and make-up. New casing string must have 2 feet long pup joint as first
           joint.

(xvi)   As alignment tool reaches the top of the connection it may require slight RH rotation of
          string to put alignment tool over the casing.

(xvii)   Continue with RH rotation until the connection is full made up. POOH with internal guide
        assembly if run.

(xviii)   Pull casing into tension and set slip and seal assembly with the desired weight.

(xix)   Pressure test as required.
