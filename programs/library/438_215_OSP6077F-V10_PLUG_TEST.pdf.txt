TECHNICAL DESCRIPTION


   The MS Plug Type Test Tool is designed to allow testing of the wellhead housing, BOP
   stack, and the casing hanger annulus seal assembly. The tool does not isolate the
   casing hanger seal assembly from test pressures.

   The design of the tool allows for testing in three (3) positions.

    1.  On the wellhead housing nominal seat

    2.  On the top of casing hangers

    3.  On the top of wear bushings

   This tool does not test with the Nominal Seat Protector (NSP) in place.

   Test tools are available with a variety of drillpipe box connections on the top and either
   pin or box connections on the bottom, as required by the customer. Washout subs may
   be readily attached below the test plug for cleaning the seal surface just prior to landing
   the test plug.

SPECIFICATIONS


   Test pressures are limited to the working pressure of the wellhead system, i.e. 18-3/4"
   system 10,000 (690 bar) or 15,000 psi (1 035 bar), 16-3/4" system 10,000 psi (690 bar),
   or the limits of other components being tested, whichever is less.

ROUTINE OPERATIONS


                   PRE-OPERATIONAL CHECKS

    1.  Remove protectors. Clean and inspect the tool joints and seal surfaces. Deburr as
         required.

    2.   Inspect the o-rings and polypak seals and replace if necessary. Lightly grease the
     OD of the tool.


                             NOTE:


 Seals may be installed on the tool and run immediately; however, it is preferred that
 polypak seals be fitted 24 hours before running. This will allow the seals to relax after
 stretching.


    3.   Verify the seals are installed in the correct position for the intended operation as
         follows (from top to bottom).

         a.   First seal: Polypak with the lips facing up; used when testing in the top of wear
            bushings.

         b.  Second seal: Polypak with the lips facing up; used when testing in the
           wellhead housing prior to any casing hangers being set.

          c.  Third seal: Polypak with the lips facing up; used when testing in the top
           (secondary seal bore) of the casing hangers. This seal is optional. The
           fourth and fifth seals must not be in place when the third seal is being
          used.

         d.  Fourth and Fifth seals: O-rings that seal in the lower ID profile (primary seal
            bore) of the casing hanger below the wear bushing latch groove. These are
           the standard seals for testing against the casing hanger bore. Use the
            optional seal (c-Third Seal) in the event the primary seal bore is
          damaged.

                    RUNNING PROCEDURE

  In situations such as severe wellhead angle, cocked casing hangers, rig position
   difficulties, as well as, when test plugs are run on 3-1/2" or smaller pipe or tubing benefit
  can be gained to assist the test plug to enter and land properly into a casing hanger
  (without damage to the o-ring) by placing some weight (a stand or two of drill pipe or
  collars) below the test plug. This not only helps centralize the test plug, but acts to pull
  the test plug into the hanger rather than push it into the hanger as is the case without
  weight below.

   1.  Retrieve the seat protector from the wellhead and any wear bushings installed in
       the BOP as required.

   2.  Pick up the test tool and make it up to the desired running string. Reminder: If a
      polypak seal is to be utilized in this test, confirm that the lips are facing up.

   3.  Measure in the hole to verify the test tool lands in the proper position by comparing
      measurements previously taken when the seat protector/wear bushing was
        retrieved.

   4.   Prior to the test plug entering the BOP, open the motion compensator and adjust it
        to support the weight of the running string. Slowly lower and land the test tool in the
       wellhead housing or on the casing hanger to be tested.

   5.  Slack off on motion compensator weight until all but 10,000 lbs (4 536 kgs) is
       supported.

   6.  Open the running string to atmosphere and  fill with water. When testing, this
       provides a visible monitor that the seals on the test tool have not been damaged.
     Damaged seals will allow test fluid to bypass the test tool and travel up the ID of the
       running string.  It is recommended that full test pressure is achieved in
      increments of 1,000 psi (68 bar) or less and that fluid volume to achieve test
      pressure is closely monitored.

   7.  Carry out test procedures as required.

   8.  Bleed off test pressure. Open the pipe rams or the bag-type preventer, slowly
        retrieve the test tool.


                            NOTE:


It is important to recover the plug tool slowly from the wellhead seat in order to avoid
pulling the polypak out of the groove.

    9.   Reinstall the seat protector in the wellhead and wear bushings in the BOP as

                            CAUTION:


 A 4-1/2 IF (NC-50) tool joint OD is 6.375" and will not pass into a 7" casing hanger.
 Where the plug tool is to be used to test a 7" hanger or wear bushing a 4-1/2 IF

                POST-OPERATIONAL MAINTENANCE

    1.  Thoroughly wash the tool with fresh water. Replace any damaged seals.

    2.  Apply thread dope to the tool joints and install protectors.

    3.  Apply a corrosion inhibitor to the tool body and install the test tool protector.

RECOMMENDED SPARES


   Selection of actual quantities for spare parts should be determined by customer
   operating personnel. As a rule of thumb, we offer the following suggestions.

   Rubber Goods          Static Seals                             - 1 replacement

                             Internal Moving Seals                - 2 replacements

                          External Seals                          - 3 replacements

                          Special Seals                           - 3 replacements

   Hardware            Socket Head Cap Screws:

                        With 1 to 10 in Parts List            - 2 spares

                        With 10 or More in Parts List       - 4 spares

                        Socket Set Screws                    - full count

   Hydraulic Hose:      Enough of each size for complete replacement

   Hose Fittings:        Enough of each size for several complete replacements

   General:            1 replacement for any sub-assembly which if
                    damaged or lost could cause a rig down situation.

DISASSEMBLY/ASSEMBLY PROCEDURES
