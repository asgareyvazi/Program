EQUIPMENT


  DIVERLESS CORROSION CAP - MS SERIES
   P/N H50458-1, H50771-1, H57192, H225307, H288500 Corrosion Cap
   P/N H50461-1 Running/Retrieval Tool

TECHNICAL TOOL DESCRIPTION


   The corrosion cap covers the interior seal surfaces and exterior profile of the wellhead
   housing during periods of temporary abandonment.

   The cap is run and retrieved with a J-Slot type tool and is secured to the housing with
   lock springs which engage the housing OD profile. The cap can be handled for
   running/retrieving with wireline using the pad eye on the stem. The tool includes a spring
   loaded retainer plate to prevent premature release from the cap. Weight down, to
   override the spring force, and right hand rotation of the running string releases the tool
   from the cap.

   Corrosion cap (P/N H288500) is a lightweight style corrosion cap that is designed to run
   with the ROV. This corrosion cap also incorporates the standard J-Slot style upper
   mandrel and can be run with the corrosion cap running/retrieval tool on drillpipe  if
   required.

   Once the cap is in place, a corrosion inhibitor may be pumped into the wellhead housing
    to displace drilling fluids, seawater, etc., providing an oil bath for the critical areas of the
   housings internal cavity. A female stab receptacle is provided for injecting the inhibitor.
   Diver or ROV intervention is required to inject the inhibitor.

ROUTINE OPERATIONS


                   PRE-OPERATIONAL CHECKS

    1.   Inspect the seal area of the inhibitor stab receptacle for trash or debris.

        Inspect the debris plug seals and insert the plug in the receptacle prior to running
        the cap.

    2.   Check the o-ring in the top ID of the cap and replace if required.

    3.   Check the condition/position of the inhibitor displacement pipe. Use rig air to verify
        the check valve is properly installed.

    4.   Confirm installation of the lock springs, if they are required. These springs may
      be removed at the operators discretion.

    5.   Check the spring action on the running tool retainer plate.

    6.   Lightly oil the interface of the cap and tool just prior to running.

                     RUNNING PROCEDURE

    1.   Position the corrosion cap on the drill floor.

    2.  Make up the running string to the running tool and lower it on to the top of the
        corrosion cap. Align the J-Slots in the tool with the pins on the cap and apply
          sufficient weight down on the tool to fully collapse the spring loaded retainer plate.
        Rotate the tool approximately 1/8 turn left hand to engage the J-Slots with the pins.
       Ensure the cap does not rotate with the tool.

        Pick up on the running string until the corrosion cap is slightly off the drill floor.
        Attempt to rotate the cap, left and right, to ensure the running tool is securely
        fastened.

    3.   Lower the assembly through the rotary table, measure in the hole, and land the cap
       on the housing. Adjust the compensator and set 5,000 lbs (2 270 kgs) down over
        the running string weight to ensure the cap has fully engaged the housing. Allow
        sufficient time for seawater or trapped air to purge through the check valve
      and displacement pipe.

    4.    Utilizing diver or ROV intervention, inject the corrosion inhibitor through the top
        stab receptacle. Pump the fluid until a pre-determined volume has been displaced
        or until the fluid is observed flowing from around the skirt of the corrosion cap.

    5.   Maintain running string weight down on the tool and rotate the string ¼ turn right
       hand to un-jay the tool from the cap. Retrieve the running string and tool to the
        surface. Observe for any weight loss in the running string, as an indicator
        that the tool has released from the cap.

                   DIVERLESS CORROSION CAP - MS SERIES


                     RETRIEVING PROCEDURE

    1.  Make up the running/retrieval tool on drillpipe and run in the hole. Use diver or ROV
         intervention to guide the tool over the cap mandrel.

    2.   Slowly rotate the drillpipe right hand until the tool J-Slots engage the cap pins.

        Apply sufficient weight down on the tool to fully collapse the spring loaded retainer
         plate.

        Slowly rotate the tool approximately 1/8 turn left hand to engage the J-Slots with
        the pins on the cap.

    3.   Pick up all the string weight and observe that the retainer plate has trapped this
       engagement.

    4.   Retrieve the corrosion cap with straight upward pull.

                      Internal Moving Seals                - 2 replacements

                    External Seals                          - 3 replacements

                   Special Seals                           - 3 replacements

               damaged or lost could cause a rig down situation
