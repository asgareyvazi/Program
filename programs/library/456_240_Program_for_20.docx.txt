
Program for 20” casing:
Attempt to POOH 13 3/8” casing and follow the steps below.
Set umbrella at the bottom of the 20” casing.
Punch the 20” casing and squeeze the 20” Depths to be discussed.
Run CBL / VDL log to check the cement behind 20”
Mill the 20” obstruction @892m
Make dummy run with the 16” hanger to see if it will go through ok POOH.
Rih and drill out the cement and umbrella and about 30m new hole.
Run the 16” liner and land of on the landing ring and cement liner.
If required check with CBL log.
Set plug just below the 16” liner hanger and squeeze cement through the 16” hanger that way you can  cement from the top side no need to set seal assembly.
This casing can be punched as well and CBL can be run again.
A small pressure test can be done on the integrity of the casing stings.
Drill out the 16” shoe and some new hole.
Run the 13 3/8” casing and cement it.
Clean out to just above the shoe and perform a CBL. If all ok.
Drill out the 13 3/8” and perform a leak off test.
